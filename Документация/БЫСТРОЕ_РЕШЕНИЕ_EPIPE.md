# Быстрое решение ошибки EPIPE в BSL Language Server

## Проблема

Ошибка `write EPIPE` или `Pending response rejected since connection got disposed` в BSL Language Server.

## Решение (3 шага)

### Шаг 1: Проверить пути и настройки

Запустите скрипт проверки:
```powershell
.\Скрипты\Очистить_Кэш_BSL_Language_Server.ps1
```

Скрипт проверит:
- Существование Java по указанному пути
- Существование JAR файла
- Версии компонентов

**Если кэш существует** - скрипт его очистит. Если нет - это нормально.

### Шаг 2: Применить упрощенные настройки

Ваш файл `C:\Users\Acer\AppData\Roaming\Cursor\User\settings.json` уже обновлен с упрощенными настройками:

- Память уменьшена до 2GB (вместо 4GB)
- Упрощены параметры кодировки
- Добавлены параметры стабильности JVM

### Шаг 3: Перезапустить Cursor

1. Закройте Cursor полностью (File → Exit)
2. Откройте Cursor заново
3. Дождитесь инициализации BSL Language Server (10-30 секунд)
4. Откройте файл `.bsl` и проверьте работу

## Если проблема сохраняется

### Вариант A: Откат на старую версию (РЕКОМЕНДУЕТСЯ)

Попробуйте установить более старую, стабильную версию BSL Language Server:

1. **Закройте Cursor полностью**

2. **Запустите скрипт:**
   ```powershell
   .\Скрипты\Скачать_Старую_Версию_BSL_Language_Server.ps1 -Version "0.25.0"
   ```

3. **Откройте Cursor заново**

Подробная инструкция: `Документация/Откат_на_Старую_Версию_BSL_Language_Server.md`

### Вариант B: Минимальные настройки

Скопируйте настройки из:
```
Настройки_Cursor/User_Settings/04_settings_minimal.json
```

В ваш `settings.json` и перезапустите Cursor.

### Вариант B: Встроенный сервер

Скопируйте настройки из:
```
Настройки_Cursor/User_Settings/05_settings_builtin_server.json
```

В ваш `settings.json` и перезапустите Cursor. Сервер загрузится автоматически.

## Проверка работы

После перезапуска:

1. Откройте файл `.bsl`
2. Откройте панель Output (View → Output)
3. Выберите "BSL Language Server" в выпадающем списке
4. Убедитесь, что нет ошибок `EPIPE`
5. Проверьте работу подсветки синтаксиса
