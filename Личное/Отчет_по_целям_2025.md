## 1. ЦЕЛИ ПО РАЗВИТИЮ

### 1.1. WEB-курс «Интеграция и обмен данными» (1С)

**Статус:** ✅ **УСПЕШНО ЗАВЕРШЕН**

**Описание курса:**
Курс предназначен для специалистов, желающих освоить механизмы взаимодействия «1С:Предприятие 8» с другими системами и организации обмена данными. Программа курса охватывает работу с файлами различных форматов (текстовые, XML, HTML), использование технологий OLE и COM, работу с внешними источниками данных, XML-технологии (XDTO), работу с JSON, создание и использование веб-сервисов, а также HTTP-сервисы.

**Результаты обучения:**

- Получены глубокие знания по интеграции систем 1С:Предприятие 8 с внешними приложениями и базами данных
- Освоены современные технологии обмена данными (XML, JSON, веб-сервисы, HTTP-сервисы)
- Приобретены практические навыки работы с OLE и COM для взаимодействия с внешними приложениями
- Изучены методы организации обмена данными через различные протоколы и форматы

**Применение полученных знаний:**
Полученные знания активно применялись при разработке интеграционных решений в рамках задач по оптимизации процессов, включая работу с внешними системами и организация обмена данными между различными информационными системами компании.

**Документ:** Свидетельство установленного образца получено.

### 1.2. Курс «Эксплуатация крупных информационных систем» (1С)

**Статус:** ✅ **УСПЕШНО ЗАВЕРШЕН**

**Описание курса:**
Курс предназначен для подготовки специалистов в области эксплуатации информационных систем на платформе «1С:Предприятие 8». Программа включает организацию эксплуатации крупной информационной системы (планирование задач, администрирование различных зон системы, мониторинг и обслуживание), конфигурирование информационной системы (настройка ОС, СУБД MS SQL Server и PostgreSQL, кластера серверов 1С), развертывание мониторинга, методики выявления и расследования проблем в крупных системах под нагрузкой, развертывание стенда в технологии 1cfresh, стандарты и требования по разработке, регламенты по обеспечению качества.

**Результаты обучения:**

- Сформировано целостное представление о компетенциях специалиста по эксплуатации информационных систем
- Освоены технологически правильные методы организации эксплуатации крупных информационных систем
- Получены знания по администрированию различных зон системы (рабочей, подготовительной, зоны разработки)
- Изучены методы мониторинга и обслуживания крупных систем
- Приобретены навыки конфигурирования СУБД (MS SQL Server, PostgreSQL) и кластера серверов 1С
- Освоены методики выявления и расследования проблем производительности в системах под нагрузкой
- Изучены стандарты и требования по разработке, регламенты по обеспечению качества

**Применение полученных знаний:**
Знания, полученные на курсе, критически важны для обеспечения стабильной работы крупных информационных систем компании. Особенно актуальны навыки по мониторингу, выявлению проблем производительности и оптимизации работы систем под нагрузкой, что напрямую связано с задачами по оптимизации процессов и предотвращению рисков RSCA.

**Документ:** Удостоверение фирмы «1С» о прохождении курса получено.

### 2.7. Техническая поддержка перехода баз 1С на PostgreSQL ⚠️ КРИТИЧНО

**Статус:** ⏸️ **УСЛОВНАЯ ЦЕЛЬ - УСЛОВИЕ НЕ НАСТУПИЛО**

**Описание:**
Цель была сформулирована как "обеспечить техническую поддержку перехода баз 1С на PostgreSQL **в случае принятия решения о переносе**". Данная цель является условной и зависит от решения руководства компании о начале миграции.

**Текущая ситуация:**
Решение о переходе баз 1С на PostgreSQL руководством компании на момент отчетного периода не было принято. В связи с этим работы по технической поддержке миграции не проводились, так как условие для начала работ (принятие решения о переносе) не наступило.

**Готовность к выполнению:**
При наличии необходимых знаний и опыта, полученных на курсе «Эксплуатация крупных информационных систем» по конфигурированию СУБД PostgreSQL, готов приступить к технической поддержке процесса перехода сразу после принятия руководством решения о миграции.

**Примечание:**
Данная цель является условной и зависит от внешнего фактора (решения руководства). Невыполнение работ по данной цели связано исключительно с тем, что условие для начала работ не наступило, а не с недостатком усилий или компетенций сотрудника.
