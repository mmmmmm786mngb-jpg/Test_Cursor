Ключевая особенность: Исполнение сделки при закрытии плановой позиции

Важно: Документ Сделка создается при создании задачи по точке маршрута ОткрытиеПлановойПозиции и сохраняется в реквизите Задача.Предмет. При закрытии плановой позиции происходит только проверка существования документа (если он еще не создан, создается новый). Проведение документа происходит при выполнении задачи по закрытию плановой позиции через механизм синхронизации статуса предмета задачи.

Последовательность выполнения:

  1. При создании задачи ОткрытиеПлановойПозиции (ОткрытиеПлановойПозицииПриСозданииЗадач):
    • Вызывается функция ОформитьОткрытиеПлановойПозиции() (ManagerModule.bsl, строка 486)
    • Создается документ ОткрытиеПлановойПозиции
    • Документ Сделка создается при открытии плановой позиции и сохраняется в Задача.Предмет
    • Документ Сделка записывается БЕЗ ПРОВЕДЕНИЯ
  2. При создании задачи ЗакрытиеПлановойПозиции (ЗакрытиеПлановойПозицииПриСозданииЗадач):
    • Вызывается функция ОформитьЗакрытиеПлановойПозиции() (ManagerModule.bsl, строка 543)
    • Проверяется существование документа Сделка по бизнес-процессу (строка 550)
    • Если документ не найден - создается новый документ Документы.Сделка.СоздатьДокумент() (строка 558)
    • Заполняются реквизиты из бизнес-процесса (дата, плановая позиция, аналитические счета, курсы, комиссии)
    • Документ записывается с режимом РежимЗаписиДокумента.Запись (строка 697) - БЕЗ ПРОВЕДЕНИЯ
    • Ссылка на документ сохраняется в Задача.Предмет (строка 706)
  3. При выполнении задачи ЗакрытиеПлановойПозиции (через ВыполнитьЗадачу):
    • Платформа 1С вызывает обработчик ЗакрытиеПлановойПозицииПриВыполнении (если есть)
    • Если установлены флаги ОпределятьКурсНаДатуОперации или ОпределятьКурсАктиваНаДатуОперации
    • Вызывается функция ПересчитатьПоКурсуОформитьЗакрытиеПлановойПозиции() для пересчета курсов
    • При записи задачи вызывается процедура ПриЗаписи (Задача.ВнебиржеваяСделка, ObjectModule.bsl, строка 247)
    • Если СинхронизоватьПредметПоЗадаче = Истина, вызывается СинхронизироватьСтатусПредметаЗадачи(Отказ) (строка 249)
    • КРИТИЧНО: В функции СинхронизироватьСтатусПредметаЗадачи (строка 31-88):
      • Проверяется: если Выполнена = Истина и документ Проведен = Ложь
      • Выполняется ДокументОбъект.Записать(РежимЗаписиДокумента.Проведение) (строка 58)
    • Это и есть исполнение сделки - документ Сделка проводится, формируются движения по регистрам

Механизм синхронизации статуса

Переменная СинхронизоватьПредметПоЗадаче устанавливается в Истина перед вызовом ВыполнитьЗадачу() (например, в ИсполнениеПлановойПозиции, строка 33). Это обеспечивает автоматическое проведение документа при выполнении задачи.

Исполнение сделки

Проведение документа Сделка при закрытии плановой позиции означает:

  • Формирование движений по регистрам бухгалтерии (Хозрасчетный, ВалютныйУчет, УправленческийУчет)
  • Отражение операции в учете (поступление/выбытие ценных бумаг)
  • Формирование проводок по счетам взаиморасчетов
  • Учет комиссий брокера и биржи
  • Расчет курсовых разниц (если применимо)

Это финальный этап исполнения сделки T+n - момент, когда сделка реально отражается в учете.
