================================================================================
СХЕМА ПРОВЕДЕНИЯ ДОКУМЕНТА СДЕЛКА ПРИ ИСПОЛНЕНИИ СДЕЛОК
================================================================================

ОПИСАНИЕ: Данная схема показывает точный момент, когда начинается проведение
          документа Сделка в процессе автоматического исполнения сделок Т+n ДУ.

================================================================================
1. ОБЩАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ СОЗДАНИЯ И ПРОВЕДЕНИЯ ДОКУМЕНТА СДЕЛКА
================================================================================

    [Шаг 1: Создание задачи по точке маршрута]
            |
            v
    [ПриСозданииЗадач для точки маршрута]
            |
            +---> [Для СделкиРЕПО - Точка: ПерваяЧастьРЕПО]
            |           |
            |           v
            |     ПерваяЧастьРЕПОПриСозданииЗадач()
            |           |
            |           +---> ОформитьСделкуРепоПервуюЧасть()
            |                   |
            |                   +---> Создать документ СделкаРЕПОПерваяНога
            |                   |
            |                   +---> Заполнить реквизиты из БП
            |                   |
            |                   +---> ТекДокумент.Записать(РежимЗаписиДокумента.Запись)
            |                           |
            |                           +---> ВАЖНО: Документ НЕ ПРОВОДИТСЯ!
            |                           |       Создается только запись документа
            |                           |
            |                   +---> Задача.Предмет = ТекДокумент.Ссылка
            |                           |
            |                           +---> Документ привязывается к задаче
            |
            +---> [Для СделкиРЕПО - Точка: ВтораяЧастьРЕПО]
            |           |
            |           v
            |     ВтораяЧастьРЕПОПриСозданииЗадач()
            |           |
            |           +---> ОформитьСделкуРепоВторуюЧасть()
            |                   |
            |                   +---> Создать документ СделкаРЕПОВтораяНога
            |                   |
            |                   +---> Заполнить реквизиты из БП
            |                   |
            |                   +---> ТекДокумент.Записать(РежимЗаписиДокумента.Запись)
            |                           |
            |                           +---> ВАЖНО: Документ НЕ ПРОВОДИТСЯ!
            |                           |       Создается только запись документа
            |                           |
            |                   +---> Задача.Предмет = ТекДокумент.Ссылка
            |                           |
            |                           +---> Документ привязывается к задаче
            |
            v
    [Шаг 2: Задача создана, документ записан, но НЕ ПРОВЕДЕН]
            |
            +---> Статус задачи: "Открыта"
            |
            +---> Статус документа: "Записан" (НЕ "Проведен")
            |
            +---> Задача.Предмет = Ссылка на документ Сделка
            |
            v
    [Шаг 3: Ожидание выполнения задачи]
            |
            +---> Задача находится в списке открытых задач
            |
            +---> СрокИсполнения наступил (в диапазоне даты исполнения)
            |
            v
    [Шаг 4: НАЧАЛО ПРОВЕДЕНИЯ - Выполнение задачи]
            |
            v
    [Вызов: Задача.ВыполнитьЗадачу()]
            |
            +---> [1] Получение объекта задачи]
            |           |
            |           v
            |     ТекОбъект = Задача.Ссылка.ПолучитьОбъект()
            |
            +---> [2] Синхронизация предмета задачи]
            |           |
            |           v
            |     ТекОбъект.СинхронизоватьПредметПоЗадаче = ИСТИНА
            |           |
            |           +---> КРИТИЧЕСКИ ВАЖНО: Этот флаг указывает платформе 1С,
            |           |       что при выполнении задачи нужно синхронизировать
            |           |       и провести документ, указанный в Задача.Предмет
            |
            +---> [3] Вызов обработчика ПриВыполнении (если есть)]
            |           |
            |           +---> Для СделкиРЕПО: Нет обработчика ПриВыполнении
            |           |       для точек ПерваяЧастьРЕПО и ВтораяЧастьРЕПО
            |           |
            |           +---> Для других точек: Может быть пересчет курсов
            |
            +---> [4] ВЫПОЛНЕНИЕ ЗАДАЧИ ПЛАТФОРМОЙ 1С]
                    |
                    +---> [4.1] Проверка прав доступа]
                    |
                    +---> [4.2] Проверка заполненности задачи]
                    |
                    +---> [4.3] СИНХРОНИЗАЦИЯ И ПРОВЕДЕНИЕ ДОКУМЕНТА]
                            |
                            +---> Платформа 1С проверяет:
                            |       - Задача.Предмет заполнен?
                            |       - СинхронизоватьПредметПоЗадаче = ИСТИНА?
                            |
                            +---> Если ДА:
                                    |
                                    +---> [МОМЕНТ НАЧАЛА ПРОВЕДЕНИЯ]
                                            |
                                            v
                                    Платформа 1С автоматически:
                                            |
                                            +---> Получает документ: Задача.Предмет.ПолучитьОбъект()
                                            |
                                            +---> Синхронизирует реквизиты документа с задачей
                                            |
                                            +---> Вызывает: Документ.Записать(РежимЗаписиДокумента.Проведение)
                                            |
                                            +---> В ЭТОТ МОМЕНТ документ Сделка ПРОВОДИТСЯ!
                                            |
                                            +---> Создаются движения по регистрам
                                            |
                                            +---> Формируются проводки
                                            |
                                            +---> Документ получает статус "Проведен"
                            |
                    +---> [4.4] Обновление статуса задачи]
                            |
                            +---> Задача.Выполнена = ИСТИНА
                            |
                            +---> Задача закрывается
                            |
                    +---> [4.5] Переход к следующей точке маршрута]
                            |
                            +---> Создание следующих задач (если есть)


================================================================================
2. ДЕТАЛЬНАЯ СХЕМА МОМЕНТА ПРОВЕДЕНИЯ ДОКУМЕНТА СДЕЛКА
================================================================================

    [Точка входа: ВыполнитьЗадачу()]
            |
            v
    ТекОбъект = Задача.Ссылка.ПолучитьОбъект()
            |
            v
    ТекОбъект.СинхронизоватьПредметПоЗадаче = ИСТИНА
            |
            v
    ТекОбъект.ВыполнитьЗадачу()
            |
            v
    [Внутри платформы 1С: ВыполнитьЗадачу()]
            |
            +---> Проверка: Задача.Предмет заполнен?
            |           |
            |           +---> НЕТ -> Пропуск проведения документа
            |           |
            |           +---> ДА -> Продолжение
            |
            +---> Проверка: СинхронизоватьПредметПоЗадаче = ИСТИНА?
            |           |
            |           +---> НЕТ -> Пропуск проведения документа
            |           |
            |           +---> ДА -> Продолжение
            |
            v
    [НАЧАЛО ПРОВЕДЕНИЯ ДОКУМЕНТА]
            |
            v
    ДокументОбъект = Задача.Предмет.ПолучитьОбъект()
            |
            v
    [Синхронизация реквизитов документа с задачей]
            |
            +---> Платформа 1С автоматически обновляет реквизиты документа
            |       на основе данных задачи (если нужно)
            |
            v
    [Проверка заполненности документа]
            |
            +---> ДокументОбъект.ПроверитьЗаполнение()
            |
            v
    [ПРОВЕДЕНИЕ ДОКУМЕНТА]
            |
            v
    ДокументОбъект.Записать(РежимЗаписиДокумента.Проведение)
            |
            +---> В ЭТОТ МОМЕНТ:
            |       |
            |       +---> Документ получает статус "Проведен"
            |       |
            |       +---> Вызывается процедура Проведение() документа
            |       |
            |       +---> Создаются движения по регистрам:
            |               - РегистрБухгалтерии.Хозрасчетный
            |               - РегистрСведений.*
            |               - РегистрНакопления.*
            |       |
            |       +---> Формируются проводки
            |       |
            |       +---> Выполняются обработчики проведения документа
            |
            v
    [Завершение проведения]
            |
            +---> Документ.Проведен = ИСТИНА
            |
            +---> Документ.ДатаПроведения = ТекущаяДатаСеанса()
            |
            v
    [Продолжение выполнения задачи]
            |
            +---> Задача.Выполнена = ИСТИНА
            |
            +---> Задача закрывается
            |
            +---> Переход к следующей точке маршрута


================================================================================
3. ВРЕМЕННАЯ ДИАГРАММА ПРОВЕДЕНИЯ ДОКУМЕНТА СДЕЛКА
================================================================================

    T0: Создание задачи по точке маршрута
            |
            v
    T1: ПриСозданииЗадач вызывается
            |
            v
    T2: ОформитьСделкуРепоПервуюЧасть() / ОформитьСделкуРепоВторуюЧасть()
            |
            v
    T3: Создание документа Сделка
            |
            +---> Документ.СоздатьДокумент()
            |
            +---> Заполнение реквизитов
            |
            v
    T4: Запись документа (БЕЗ ПРОВЕДЕНИЯ)
            |
            +---> Документ.Записать(РежимЗаписиДокумента.Запись)
            |
            +---> Статус: "Записан" (НЕ "Проведен")
            |
            v
    T5: Привязка документа к задаче
            |
            +---> Задача.Предмет = Документ.Ссылка
            |
            v
    T6: Задача создана, ожидает выполнения
            |
            +---> Статус задачи: "Открыта"
            |
            +---> Статус документа: "Записан"
            |
            v
    T7: Наступление срока исполнения
            |
            +---> СрокИсполнения в диапазоне даты исполнения
            |
            v
    T8: Вызов ВыполнитьЗадачу()
            |
            +---> ТекОбъект.СинхронизоватьПредметПоЗадаче = ИСТИНА
            |
            v
    T9: [МОМЕНТ НАЧАЛА ПРОВЕДЕНИЯ]
            |
            +---> Платформа 1С определяет, что нужно провести документ
            |
            v
    T10: Получение объекта документа
            |
            +---> ДокументОбъект = Задача.Предмет.ПолучитьОбъект()
            |
            v
    T11: Синхронизация реквизитов
            |
            +---> Обновление реквизитов документа из задачи
            |
            v
    T12: Проверка заполненности
            |
            +---> ДокументОбъект.ПроверитьЗаполнение()
            |
            v
    T13: [ПРОВЕДЕНИЕ ДОКУМЕНТА]
            |
            +---> ДокументОбъект.Записать(РежимЗаписиДокумента.Проведение)
            |
            +---> Выполнение процедуры Проведение()
            |
            +---> Создание движений по регистрам
            |
            +---> Формирование проводок
            |
            v
    T14: Завершение проведения
            |
            +---> Документ.Проведен = ИСТИНА
            |
            +---> Документ.ДатаПроведения установлена
            |
            v
    T15: Завершение выполнения задачи
            |
            +---> Задача.Выполнена = ИСТИНА
            |
            +---> Задача закрыта


================================================================================
4. УСЛОВИЯ ПРОВЕДЕНИЯ ДОКУМЕНТА СДЕЛКА
================================================================================

    Документ Сделка БУДЕТ ПРОВЕДЕН, если выполнены ВСЕ условия:
            |
            +---> [1] Задача.Предмет заполнен]
            |           |
            |           +---> Задача.Предмет <> Неопределено
            |           |
            |           +---> Задача.Предмет содержит ссылку на документ Сделка
            |
            +---> [2] Синхронизация предмета включена]
            |           |
            |           +---> Задача.СинхронизоватьПредметПоЗадаче = ИСТИНА
            |           |
            |           +---> Этот флаг устанавливается перед вызовом ВыполнитьЗадачу()
            |
            +---> [3] Документ существует и не удален]
            |           |
            |           +---> Документ.ПометкаУдаления = ЛОЖЬ
            |           |
            |           +---> Документ доступен для проведения
            |
            +---> [4] Документ заполнен корректно]
            |           |
            |           +---> Документ.ПроверитьЗаполнение() = ИСТИНА
            |           |
            |           +---> Все обязательные реквизиты заполнены
            |
            +---> [5] Есть права на проведение]
            |           |
            |           +---> Пользователь имеет права на проведение документа
            |           |
            |           +---> Нет блокировок на проведение
            |
            v
    [Если ВСЕ условия выполнены -> Документ ПРОВОДИТСЯ]
    [Если хотя бы одно условие НЕ выполнено -> Документ НЕ ПРОВОДИТСЯ]


================================================================================
5. КОД, ОТВЕТСТВЕННЫЙ ЗА ПРОВЕДЕНИЕ
================================================================================

    [Место в коде: ИсполнениеПлановойПозиции()]
            |
            v
    Для каждого ТекЗадача Из ОткрытыеЗадачи Цикл
            |
            +---> ТекОбъект = ТекЗадача.Ссылка.ПолучитьОбъект()
            |
            +---> ТекОбъект.СинхронизоватьПредметПоЗадаче = ИСТИНА
            |       |
            |       +---> КРИТИЧЕСКИ ВАЖНО: Этот флаг включает автоматическое
            |       |       проведение документа при выполнении задачи
            |
            +---> ТекОбъект.ВыполнитьЗадачу()
            |       |
            |       +---> Внутри этого метода платформа 1С:
            |               |
            |               +---> Проверяет наличие Задача.Предмет
            |               |
            |               +---> Проверяет СинхронизоватьПредметПоЗадаче = ИСТИНА
            |               |
            |               +---> Если оба условия выполнены:
            |                       |
            |                       +---> Автоматически вызывает:
            |                               Документ.Записать(РежимЗаписиДокумента.Проведение)


================================================================================
6. ОТЛИЧИЯ ДЛЯ РАЗНЫХ ТИПОВ ДОКУМЕНТОВ
================================================================================

    [Документ: СделкаРЕПОПерваяНога]
            |
            +---> Создается в: ОформитьСделкуРепоПервуюЧасть()
            |
            +---> Записывается: РежимЗаписиДокумента.Запись
            |
            +---> Проводится: При ВыполнитьЗадачу() для точки ПерваяЧастьРЕПО
            |
            +---> Момент проведения: T13 (см. временную диаграмму)
            |
    |
    [Документ: СделкаРЕПОВтораяНога]
            |
            +---> Создается в: ОформитьСделкуРепоВторуюЧасть()
            |
            +---> Записывается: РежимЗаписиДокумента.Запись
            |
            +---> Проводится: При ВыполнитьЗадачу() для точки ВтораяЧастьРЕПО
            |
            +---> Момент проведения: T13 (см. временную диаграмму)
            |
    |
    [Другие документы (ОткрытиеПлановойПозиции, ОперацияПоСчетуДУ и т.д.)]
            |
            +---> Аналогичная логика:
            |       - Создание при ПриСозданииЗадач
            |       - Запись в режиме Запись
            |       - Проведение при ВыполнитьЗадачу()


================================================================================
7. КЛЮЧЕВЫЕ МОМЕНТЫ
================================================================================

    ВАЖНО ПОНИМАТЬ:
            |
            +---> [1] Документ Сделка НЕ ПРОВОДИТСЯ при создании]
            |           |
            |           +---> При ПриСозданииЗадач документ только ЗАПИСЫВАЕТСЯ
            |           |
            |           +---> Режим: РежимЗаписиДокумента.Запись (НЕ Проведение)
            |
            +---> [2] Проведение происходит АВТОМАТИЧЕСКИ платформой 1С]
            |           |
            |           +---> При вызове ВыполнитьЗадачу()
            |           |
            |           +---> Если установлен флаг СинхронизоватьПредметПоЗадаче
            |           |
            |           +---> Если у задачи есть предмет (документ)
            |
            +---> [3] Момент начала проведения - ВНУТРИ ВыполнитьЗадачу()]
            |           |
            |           +---> Не в обработчике ПриВыполнении
            |           |
            |           +---> Не в коде пользователя
            |           |
            |           +---> В стандартном механизме платформы 1С
            |
            +---> [4] Проведение происходит ДО завершения задачи]
            |           |
            |           +---> Сначала проводится документ
            |           |
            |           +---> Потом задача помечается как выполненная
            |
            +---> [5] Если проведение не удалось - задача не выполняется]
            |           |
            |           +---> Ошибка проведения = ошибка выполнения задачи
            |           |
            |           +---> Задача остается открытой
