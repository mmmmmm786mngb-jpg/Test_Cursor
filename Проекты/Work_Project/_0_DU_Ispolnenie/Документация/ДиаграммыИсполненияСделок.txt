8. СХЕМА РАСЧЕТА КОМИССИИ
================================================================================

    РассчитатьКомиссиюОбороотовВБизнесПроцессах()
            |
            +---> [1] Получение брокеров]
            |           |
            |           +---> Запрос: Контрагенты с флагом "Расчет комиссии от оборотов"
            |
            +---> [2] Получение сделок за день]
            |           |
            |           +---> Запрос: Сделки Tn + Документ.Сделка
            |           |
            |           +---> Фильтр: Дата = ДатаИсполнения
            |           |
            |           +---> Фильтр: Контрагент в списке брокеров
            |
            +---> [3] Группировка по АналитическийСчетДС]
            |           |
            |           +---> Свертка по АС
            |           |
            |           +---> ОбщаяСуммаОборот = Итог("Сумма")
            |
            +---> [4] Расчет комиссии для каждого АС]
                    |
                    +---> Для каждого АналитическийСчетДС:
                            |
                            +---> Получить ДоговорБрокера
                            |
                            +---> Вызвать РезультатАлгоритма(ДоговорБрокера, ПараметрыСделки)
                            |
                            +---> Получить КомиссияБрокераОбщая
                            |
                            +---> [Распределение по сделкам]
                                    |
                                    +---> Для каждой сделки:
                                            |
                                            +---> НоваяКомиссия = (СуммаСделки / ОбщаяСумма) * КомиссияБрокераОбщая
                                            |
                                            +---> Корректировка последней сделки (для точности)
                                            |
                                            +---> Обновить КомиссияБрокера в документе
