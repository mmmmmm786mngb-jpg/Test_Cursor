================================================================================
РАЗЛИЧИЯ В ИСПОЛНЕНИИ СДЕЛОК ДЛЯ ДАТЫ Т (ТЕКУЩАЯ) И Т-1 (ВЧЕРАШНЯЯ)
================================================================================

ОПИСАНИЕ: Данная схема показывает различия в логике исполнения сделок
          в зависимости от даты регламентного задания - Т (текущая дата)
          или Т-1 (вчерашняя дата).


================================================================================
ЗАЧЕМ ЗАПУСКАЮТСЯ ДВА РЕГЛАМЕНТА (Т И Т-1)?
================================================================================

В системе настроены ДВА регламентных задания, оба работают в многопоточном
режиме, но выполняют разные задачи:

    [Регламент 1: Т (текущая дата)]
            |
            +---> НАЗНАЧЕНИЕ: Основное исполнение сделок на текущий день
            |
            +---> КОГДА ЗАПУСКАЕТСЯ: По расписанию в течение рабочего дня
            |
            +---> ЧТО ДЕЛАЕТ:
                    |
                    +---> Выполняет задачи со СрокИсполнения = СЕГОДНЯ
                    |
                    +---> Рассчитывает комиссию по сделкам за СЕГОДНЯШНИЙ день
                    |
                    +---> Обрабатывает текущие сделки в реальном времени
                    |
                    +---> Основной рабочий процесс

    [Регламент 2: Т-1 (вчерашняя дата)]
            |
            +---> НАЗНАЧЕНИЕ: Доработка и исправление незавершенных задач
            |
            +---> КОГДА ЗАПУСКАЕТСЯ: Обычно утром следующего дня
            |
            +---> ЧТО ДЕЛАЕТ:
                    |
                    +---> Выполняет задачи со СрокИсполнения = ВЧЕРА
                    |
                    +---> Рассчитывает/пересчитывает комиссию за ВЧЕРАШНИЙ день
                    |
                    +---> Обрабатывает задачи, которые НЕ были выполнены вчера
                    |
                    +---> Исправляет ошибки предыдущего дня
                    |
                    +---> Дорабатывает незавершенные операции

    [ПОЧЕМУ НУЖНЫ ОБА РЕГЛАМЕНТА:]
            |
            +---> [1] Обеспечение непрерывности процесса]
            |           |
            |           +---> Регламент Т: Обрабатывает текущие сделки
            |           |
            |           +---> Регламент Т-1: Дорабатывает вчерашние сделки
            |           |
            |           +---> Гарантирует, что все задачи будут выполнены
            |
            +---> [2] Обработка ошибок и сбоев]
            |           |
            |           +---> Если вчера был сбой - регламент Т-1 исправит
            |           |
            |           +---> Если задачи не выполнились - регламент Т-1 доработает
            |           |
            |           +---> Если были ошибки в расчете комиссии - регламент Т-1 пересчитает
            |
            +---> [3] Пересчет комиссии]
            |           |
            |           +---> Если параметры расчета изменились
            |           |
            |           +---> Если нужно пересчитать комиссию за вчера
            |           |
            |           +---> Если были изменения в договорах или настройках
            |
            +---> [4] Обработка поздних поступлений данных]
                    |
                    +---> Если данные по вчерашним сделкам поступили поздно
                    |
                    +---> Если нужно обработать сделки, созданные после основного регламента
                    |
                    +---> Если были корректировки вчерашних документов

    [ТИПИЧНЫЙ СЦЕНАРИЙ РАБОТЫ:]
            |
            +---> День 1 (14.01.2024):
            |       |
            |       +---> 08:00 - Регламент Т запускается
            |       |       |
            |       |       +---> Выполняет задачи за 14.01.2024
            |       |       |
            |       |       +---> Рассчитывает комиссию за 14.01.2024
            |       |
            |       +---> 12:00 - Регламент Т запускается повторно
            |       |       |
            |       |       +---> Выполняет новые задачи за 14.01.2024
            |       |
            |       +---> 18:00 - Регламент Т запускается еще раз
            |               |
            |               +---> Финальная обработка за 14.01.2024
            |
            +---> День 2 (15.01.2024):
                    |
                    +---> 08:00 - Регламент Т-1 запускается
                    |       |
                    |       +---> Дорабатывает незавершенные задачи за 14.01.2024
                    |       |
                    |       +---> Пересчитывает комиссию за 14.01.2024 (если нужно)
                    |       |
                    |       +---> Исправляет ошибки за 14.01.2024
                    |
                    +---> 08:30 - Регламент Т запускается
                            |
                            +---> Начинает обработку задач за 15.01.2024

    [ПРЕИМУЩЕСТВА ДВУХ РЕГЛАМЕНТОВ:]
            |
            +---> [1] Надежность]
            |           |
            |           +---> Если один регламент не сработал - второй подстрахует
            |           |
            |           +---> Гарантия выполнения всех задач
            |
            +---> [2] Гибкость]
            |           |
            |           +---> Можно пересчитать вчерашние данные
            |           |
            |           +---> Можно исправить ошибки без влияния на текущий день
            |
            +---> [3] Разделение ответственности]
                    |
                    +---> Регламент Т: Текущие операции
                    |
                    +---> Регламент Т-1: Доработка и исправления
                    |
                    +---> Четкое разделение задач

    [ВАЖНО ПОНИМАТЬ:]
            |
            +---> Оба регламента используют ОДИНАКОВУЮ логику выполнения
            |
            +---> Различается ТОЛЬКО дата, по которой выбираются задачи
            |
            +---> Регламент Т-1 НЕ является заменой регламента Т
            |
            +---> Регламент Т-1 - это ДОПОЛНИТЕЛЬНЫЙ механизм доработки

================================================================================
1. ОСНОВНОЕ РАЗЛИЧИЕ - УСТАНОВКА ДАТЫ ИСПОЛНЕНИЯ
================================================================================

    [Регламентное задание]
            |
            +---> [Вариант 1: Обычный режим (Т)]
            |           |
            |           v
            |     ДатаИсполнения = ТекущаяДата()
            |           |
            |           +---> Пример: Если сегодня 15.01.2024
            |           |       То ДатаИсполнения = 15.01.2024 00:00:00
            |
            +---> [Вариант 2: Режим Т-1]
                    |
                    v
              ДатаИсполнения = ТекущаяДата() - 86400
                    |
                    +---> Пример: Если сегодня 15.01.2024
                            То ДатаИсполнения = 14.01.2024 00:00:00
                            (86400 секунд = 1 день)


================================================================================
2. РАЗЛИЧИЯ В ВЫБОРКЕ ЗАДАЧ
================================================================================

    [Запрос: ПолучитьОткрытыеЗадачиПоСделкеTn(Дата)]
            |
            +---> Условие в запросе:
            |       |
            |       v
            |     ВнебиржеваяСделка.СрокИсполнения МЕЖДУ &ДатаНачала И &ДатаОкончания
            |
            +---> Параметры запроса:
                    |
                    +---> ДатаНачала = НачалоДня(Дата)
                    |
                    +---> ДатаОкончания = КонецДня(Дата)

    [Для Т (текущая дата):]
            |
            +---> ДатаНачала = НачалоДня(ТекущаяДата())
            |       |
            |       +---> Пример: 15.01.2024 00:00:00
            |
            +---> ДатаОкончания = КонецДня(ТекущаяДата())
            |       |
            |       +---> Пример: 15.01.2024 23:59:59
            |
            +---> ВЫБИРАЮТСЯ задачи:
                    |
                    +---> СрокИсполнения = 15.01.2024 (сегодня)
                    |
                    +---> Задачи, которые должны быть выполнены сегодня

    [Для Т-1 (вчерашняя дата):]
            |
            +---> ДатаНачала = НачалоДня(ТекущаяДата() - 86400)
            |       |
            |       +---> Пример: 14.01.2024 00:00:00
            |
            +---> ДатаОкончания = КонецДня(ТекущаяДата() - 86400)
            |       |
            |       +---> Пример: 14.01.2024 23:59:59
            |
            +---> ВЫБИРАЮТСЯ задачи:
                    |
                    +---> СрокИсполнения = 14.01.2024 (вчера)
                    |
                    +---> Задачи, которые должны были быть выполнены вчера
                    |
                    +---> ВАЖНО: Это задачи, которые НЕ были выполнены вчера
                            и остались открытыми

            |       v

                    |

                    +---> По оборотам за СЕГОДНЯШНИЙ день

    [Для Т-1 (вчерашняя дата):]
            |
            +---> Дата = НачалоДня(ТекущаяДата() - 86400)
            |       |
            |       +---> Пример: 14.01.2024 00:00:00
            |

                    |
                    +---> По оборотам за ВЧЕРАШНИЙ день
                    |
                    +---> ВАЖНО: Пересчет комиссии для вчерашних сделок,
                            которые могли быть созданы или изменены позже

6. ПРАКТИЧЕСКОЕ ПРИМЕНЕНИЕ РЕЖИМА Т-1
================================================================================

    [Когда используется Т-1:]
            |
            +---> [1] Доработка незавершенных задач]
            |           |
            |           +---> Если вчера не все задачи были выполнены
            |           |
            |           +---> Повторное выполнение задач за вчера
            |
            +---> [2] Пересчет комиссии]
            |           |
            |           +---> Если нужно пересчитать комиссию за вчерашний день
            |           |
            |           +---> После изменения параметров расчета
            |
            +---> [3] Исправление ошибок]
                    |
                    +---> Если вчера были ошибки при выполнении
                    |
                    +---> Повторное выполнение для исправления

    [Пример сценария использования Т-1:]
            |
            +---> День 1 (14.01.2024):
            |       |
            |       +---> Регламент выполнился с ошибками
            |       |
            |       +---> Часть задач не была выполнена
            |       |
            |       +---> Задачи остались открытыми
            |
            +---> День 2 (15.01.2024):
                    |
                    +---> Утром запускается регламент Т-1
                    |
                    +---> Выполняются задачи за 14.01.2024
                    |
                    +---> Пересчитывается комиссия за 14.01.2024
                    |
                    +---> Исправляются ошибки предыдущего дня

8. ИСПОЛЬЗОВАНИЕ ДАТЫ В РАЗНЫХ МЕСТАХ КОДА
================================================================================

    [Место 1: Выборка задач]
            |
            +---> ПолучитьОткрытыеЗадачиПоСделкеTn(Дата)
            |       |
            |       +---> Запрос: СрокИсполнения МЕЖДУ НачалоДня(Дата) И КонецДня(Дата)
            |       |

    [Место 2: Расчет комиссии]
            |
            +---> РассчитатьКомиссиюОбороотовВБизнесПроцессах()
            |       |
            |       +---> Запрос: НАЧАЛОПЕРИОДА(СделкиTn.Дата, ДЕНЬ) = НачалоДня(ДатаИсполнения)
            |       |

            |       +---> Для Т-1: комиссия за вчера
            |

                    |

                    |
                    +---> Для Т: документы за сегодня
                    +---> Для Т-1: документы за вчера

    [Место 3: Формирование отчетов]
            |
            +---> ПредставлениеНастроек = "Период с:"+Формат(ДатаИсполнения,"ДФ=dd.MM.yyyy")
            |
            +---> Для Т: "Период с: 15.01.2024"
            +---> Для Т-1: "Период с: 14.01.2024"
            |
            +---> Тема email: "Фоновое исполнение сделок T+n (Потоковое выполнение) На Т-1"
                    |
                    +---> Для Т-1 добавляется пометка "На Т-1" в тему письма
