================================================================================

ОПИСАНИЕ: Данный документ содержит детальное описание последовательности
          проведения документа Сделка, включая все этапы, процедуры и
          формирование движений по регистрам.

================================================================================
1. ОБЩАЯ СХЕМА ПРОВЕДЕНИЯ ДОКУМЕНТА СДЕЛКА
================================================================================

    [Вызов: Документ.Записать(РежимЗаписиДокумента.Проведение)]
            |
            v
    [Этап 1: ПередЗаписью()]
            |
            +---> Подготовка данных документа
            |
            +---> Дозаполнение реквизитов
            |
            +---> Проверка заполненности
            |
            v
    [Этап 2: Запись документа]
            |
            +---> Сохранение документа в базе
            |
            v
    [Этап 3: ПриЗаписи()]
            |
            +---> Сохранение фактической даты перерегистрации
            |
            v
    [Этап 4: ОбработкаПроведения()]
            |
            +---> Подготовка наборов записей
            |
            +---> Установка параметров проведения
            |
            +---> Установка блокировок
            |
            +---> Формирование движений по регистрам
            |
            v
    [Этап 5: Запись движений]
            |
            +---> Сохранение движений в регистрах
            |
            v
    [Завершение проведения]
            |
            +---> Документ.Проведен = ИСТИНА
            |
            +---> Документ.ДатаПроведения = ТекущаяДатаСеанса()


================================================================================
2. ЭТАП 1: ПЕРЕДЗАПИСЬЮ() - ПОДГОТОВКА ДАННЫХ
================================================================================

    Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
            |
            +---> [1] Отмена автрегистрации по плану обмена]
            |           |
            |           +---> Если БизнесПроцесс заполнен
            |           |
            |           +---> ПланыОбмена.ВыгрузкаДУFinance.ОтменитьАвтоРегистрациюОбъектаПоПлану()
            |
            +---> [2] Дозаполнение дополнительных расходов]
            |           |
            |           +---> Свертка ДопРасходы по ключевым полям
            |           |
            |           +---> Для каждой строки ДопРасходы:
            |                   |
            |                   +---> Дозаполнение Контрагент и ДоговорКонтрагента
            |                   |
            |                   +---> Дозаполнение ВалютаКомиссии, КурсКомиссии, КратностьКомиссии
            |                   |
            |                   +---> Пересчет СтоимостьДопРасходов в валюту документа
            |                   |
            |                   +---> Подсчет СуммаДопРасходов
            |
            +---> [3] Дозаполнение основных реквизитов]
            |           |
            |           +---> СуммаДокумента = Сумма
            |           |
            |           +---> ФизическоеМестоХраненияДС (из АналитическийСчетДС)
            |           |
            |           +---> Если режим "Только бухгалтерский учет":
            |                   |
            |                   +---> ВУ = ЛОЖЬ
            |                   +---> УУ = ЛОЖЬ
            |                   +---> АналитическийСчет = Неопределено
            |                   +---> АналитическийСчетДС = Неопределено
            |
            +---> [4] Специальная обработка для продажи]
            |           |
            |           +---> Если ВидОперации = Продажа:
            |                   |
            |                   +---> Для всех строк ДопРасходы:
            |                           ВключатьВСтоимость = 0
            |
            +---> [5] Обработка блокирования ДС]
            |           |
            |           +---> Если НЕ ВнебиржеваяСделка ИЛИ ВидОперации = Продажа
            |           |       ИЛИ ПлатежныеУсловияСделки <> ПоставкаПротивПлатежа:
            |           |
            |           +---> БлокированиеДС = ЛОЖЬ
            |
            +---> [6] Дозаполнение Биржа]
            |           |
            |           +---> Если НЕ ВнебиржеваяСделка И Биржа пустая
            |           |       И АналитическийСчетДС заполнен:
            |           |
            |           +---> Биржа = АналитическийСчетДС.Биржа
            |
            +---> [7] Дозаполнение роли и идентификатора]
            |           |
            |           +---> Если СделкаУКвКачестве пустая:
            |                   |
            |                   +---> СделкаУКвКачестве = ОбщегоНазначенияДУ.РольПрофУчастникаПриЗаключенииСделки()
            |           |
            |           +---> Если ИдентификаторПорученияКлиента не заполнен:
            |                   |
            |                   +---> ИдентификаторПорученияКлиента = ОбщегоНазначенияДУ.ПолучитьИдентификаторПорученияКлиента()
            |
            +---> [8] Обработка номера входящего документа]
            |           |
            |           +---> Если ПометкаУдаления И НомерВходящегоДокумента не начинается с "_":
            |                   |
            |                   +---> НомерВходящегоДокумента = "_" + НомерВходящегоДокумента
            |           |
            |           +---> Если НЕ ПометкаУдаления И НомерВходящегоДокумента начинается с "_":
            |                   |
            |                   +---> НомерВходящегоДокумента = Убрать "_" из начала
            |
            +---> [9] Специальная обработка для облигаций HTM]
                    |
                    +---> Если Актив = Облигация И ТипПортфеля = ИнвестицииДоПогашения
                    |       И ВидОперации = Поступление:
                    |
                    +---> СчетУчетаАктива = ОблигацииУдерживаемыеДоПогашения


================================================================================
3. ЭТАП 2: ПРИЗАПИСИ() - СОХРАНЕНИЕ ФАКТИЧЕСКОЙ ДАТЫ
================================================================================

    Процедура ПриЗаписи(Отказ)
            |
            +---> [1] Проверка обмена данными]
            |           |
            |           +---> Если ОбменДанными.Загрузка -> Возврат
            |
            +---> [2] Сохранение фактической даты перерегистрации]
                    |
                    +---> Если БизнесПроцесс заполнен И (ВнебиржеваяСделка ИЛИ СделкиTn):
                    |       |
                    |       +---> Если НЕ Отказ И НЕ ПометкаУдаления И Проведен:
                    |               |
                    |               +---> ФактДатаПеререгистрации = Дата
                    |               |
                    |               +---> Если ВнебиржеваяСделка И ЧастичноеИсполнение
                    |               |       И НЕ ПоследнееИсполнение:
                    |               |
                    |               +---> ФактДатаПеререгистрации = '00010101'
                    |               |
                    |               +---> Если ФактДатаПеререгистрации <> '00010101':
                    |                       |
                    |                       +---> РегистрыСведений.ФактДатыПоставкиОплатыСделок.УстановитьФактическуюДатуПоставкиОплаты()
                    |
                    +---> [3] Очистка фактической даты]
                            |
                            +---> Если ПометкаУдаления ИЛИ НЕ Проведен:
                                    |
                                    +---> РегистрыСведений.ФактДатыПоставкиОплатыСделок.УдалитьФактическуюДатуПоставкиОплаты()


================================================================================
4. ЭТАП 3: ОБРАБОТКАПРОВЕДЕНИЯ() - ОСНОВНАЯ ПРОЦЕДУРА ПРОВЕДЕНИЯ
================================================================================

    Процедура ОбработкаПроведения(Отказ, РежимПроведения)
            |
            v
    [Шаг 1: Подготовка наборов записей]
            |
            +---> ПроведениеСервер.ПодготовитьНаборыЗаписейКПроведению(ЭтотОбъект)
            |       |
            |       +---> Инициализация наборов записей для всех регистров
            |       |
            |       +---> Подготовка к записи движений
            |
            +---> Если РучнаяКорректировка:
                    |
                    +---> Возврат (движения формируются вручную)
            |
            v
    [Шаг 2: Проверка условий проведения]
            |
            +---> Если Отказ ИЛИ (НЕ БУ И НЕ УУ И НЕ ВУ):
                    |
                    +---> Возврат (нет учета для проведения)
            |
            v
    [Шаг 3: Установка дополнительных параметров]
            |
            +---> УстановитьДополнительныеПараметрыПроведения(Отказ)
            |       |
            |       +---> Получение значений параметров договора ДУ:
            |               - ПорогВключенияРасходовВСтоимость
            |               - МетодСписанияПоПартиям
            |               - ВестиРасчетыСБрокеромНа55
            |               - СчетВыручки
            |               - СчетВыручкиПриПогашенииОблигации
            |               - СчетСписанияСебестоимости
            |               - СчетКомиссийПриПродаже
            |               - УчетЧастичногоПогашенияОблигаций
            |               - ВестиУчетУКДНаСчете58
            |               - ВестиУчетНКДНаСчете58
            |               - ПартионныйУчетПереоценки
            |               - НалоговыйУчетДопРасходов
            |               - УчитыватьПогрешностьОкрПриСписанииПереоценки
            |               - РаздельныйАналитическийУчетУКДиНКД
            |               - РаздельныйАналитическийУчетСебестоимости
            |               - УчетУКДПоВидуОбращаемостиЦБ
            |       |
            |       +---> Получение ВалютаРегл = ОбщегоНазначенияДУ.ВалютаРеглУчета()
            |       |
            |       +---> Определение СчетРасчетовБрокера:
            |               - Если ВестиРасчетыНаСчете55 = ИСТИНА:
            |                   СчетРасчетовБрокера = РасчетыБрокераПоСделкам55
            |               - Иначе:
            |                   СчетРасчетовБрокера = РасчетыБрокераПоСделкам
            |       |
            |       +---> Получение ОбъектПоАктиву и ВидАктива
            |       |
            |       +---> Получение ТаблицаОНВ = ПолучитьСуммуОНВ()
            |       |
            |       +---> УстановитьПараметрыОблигации(Отказ)
            |       |
            |       +---> УстановитьСуммуДопРасходов(Отказ)
            |       |
            |       +---> УстановитьФлагиПереоценки()
            |       |
            |       +---> Установка флагов учета:
            |               - ВестиТолькоБухгалтерскийУчет
            |               - ВестиПолныйУчет
            |               - ВестиУчетКупонногоДоходаВРазрезеПартий
            |               - ВестиУчетПереоценкиВРазрезеПартий
            |
            v
    [Шаг 4: Установка блокировок]
            |
            +---> УстановитьБлокировку()
            |       |
            |       +---> Создание БлокировкаДанных
            |       |
            |       +---> Если БУ:
            |               |
            |               +---> Если НЕ Поступление:
            |                       |
            |                       +---> УстановкитьБлокировкиПоЦБ(Блокировка, ЦБОбъект)
            |                               |
            |                               +---> Блокировка РегистрБухгалтерии.Хозрасчетный:
            |                                       - ДоговорДУ
            |                                       - Валюта
            |                                       - Счет (СчетУчетаАктива)
            |                                       - Субконто1 (ЦБОбъект)
            |                               |
            |                               +---> Если ВУ:
            |                                       |
            |                                       +---> Блокировка РегистрБухгалтерии.Хозрасчетный:
            |                                               - Счет (ВУЦБ)
            |                                               - Субконто1 (АналитическийСчет)
            |                                               - Субконто2 (ЦБОбъект)
            |               |
            |               +---> УстановкитьБлокировкиПоВзаиморасчетам(Блокировка)
            |                       |
            |                       +---> Блокировка РегистрБухгалтерии.Хозрасчетный:
            |                               - Счет (СчетУчетаРасчетовСКонтрагентом)
            |                               - Субконто1 (Контрагент)
            |                               - Субконто2 (ДоговорКонтрагента)
            |                       |
            |                       +---> Блокировка РегистрБухгалтерии.Хозрасчетный:
            |                               - Счет (СчетУчетаРасчетовПоАвансам)
            |                               - Субконто1 (Контрагент)
            |                               - Субконто2 (ДоговорКонтрагента)
            |       |
            |       +---> Если УУ:
            |               |
            |               +---> Если НЕ Поступление:
            |                       |
            |                       +---> Блокировка РегистрНакопления.СтоимостьАктивовУправленческий:
            |                               - ДоговорДУ
            |                               - Валюта
            |                               - Актив
            |       |
            |       +---> Блокировка.Заблокировать()
            |
            v
    [Шаг 5: Формирование движений по бухгалтерскому учету]
            |
            +---> БухгалтерскийУчет(Отказ)
            |       |
            |       +---> Если ВидОперации = Поступление:
            |               |
            |               +---> СформироватьДвиженияЗачетАвансов(Отказ)
            |               |
            |               +---> СформироватьДвиженияПоступлениеАктивов(Отказ)
            |               |
            |               +---> СформироватьДвиженияПоступлениеДопРасходов(Отказ)
            |               |
            |               +---> Если ЭтоОблигация:
            |                       |
            |                       +---> СформироватьДвиженияПоступлениеНКД(Отказ)
            |               |
            |               +---> СформироватьДвиженияРазблокировкаДС(Отказ)
            |       |
            |       +---> Если ВидОперации = Продажа:
            |               |
            |               +---> ПараметрыПроведения = ТаблицыПоПродажам_БУ(Отказ)
            |               |       |
            |               |       +---> Подготовка таблиц для расчета себестоимости
            |               |       +---> Получение остатков активов
            |               |       +---> Расчет параметров списания
            |               |
            |               +---> Создание ТаблицаПродажи (структура для движений)
            |               |
            |               +---> СформироватьДвиженияЗачетАвансов(Отказ)
            |               |
            |               +---> СформироватьДвиженияСписаниеАктивов(Отказ)
            |               |
            |               +---> СформироватьДвиженияСписаниеПереоценки(Отказ)
            |               |
            |               +---> СформироватьДвиженияСписаниеДопРасходов(Отказ)
            |               |
            |               +---> СформироватьДвиженияСписаниеДопРасходовНУ(Отказ)
            |               |
            |               +---> СформироватьДвиженияРеализация(Отказ)
            |               |
            |               +---> Если ЭтоОблигация:
            |                       |
            |                       +---> СформироватьДвиженияДоходОтНКД(Отказ)
            |                       |
            |                       +---> СформироватьДвиженияСписаниеНКД(Отказ)
            |                       |
            |                       +---> СформироватьДвиженияПоОтложеннойВыручке(Отказ)
            |
            v
    [Шаг 6: Формирование движений по регистру Закупки]
            |
            +---> Закупки(Отказ)
            |       |
            |       +---> Если ВидОперации = Поступление:
            |               |
            |               +---> Движение = Движения.Закупки.Добавить()
            |               |
            |               +---> Заполнение реквизитов движения:
            |                       - Период = Дата
            |                       - ДоговорДУ
            |                       - Контрагент
            |                       - Актив
            |                       - Количество
            |                       - Валюта = ВалютаЦБ
            |                       - ВалютнаяСумма = СуммаВВалютеНоминальнойСтоимости + СуммаДопРасходовВСтоимостьВалЦБ
            |                       - Стоимость = СуммаРегл + СуммаДопРасходовВСтоимостьРегл
            |                       - ДопЗатратыВал = СуммаДопРасходовВСтоимостьВалЦБ
            |                       - ДопЗатраты = СуммаДопРасходовВСтоимостьРегл
            |               |
            |               +---> Движения.Закупки.Записывать = ИСТИНА
            |
            v
    [Шаг 7: Формирование движений по внутреннему учету (ВУ)]
            |
            +---> ВнутреннийУчет(Отказ)
            |       |
            |       +---> Если ВидОперации = Поступление:
            |               |
            |               +---> ДвижениеВУ_Поступление(Отказ)
            |                       |
            |                       +---> Формирование проводок по счетам ВУ
            |                       +---> Учет поступления активов на забалансовых счетах
            |       |
            |       +---> Если ВидОперации = Продажа:
            |               |
            |               +---> ПодготовитьТаблицуОстатковАктива_ВУ(Отказ)
            |               |
            |               +---> ДвижениеВУ_Продажа(Отказ)
            |                       |
            |                       +---> Формирование проводок по списанию активов
            |                       +---> Учет списания активов с забалансовых счетов
            |       |
            |       +---> Если НЕ (ВнебиржеваяСделка ИЛИ ПлановаяПозиция):
            |               |
            |               +---> ПереоценкаСчетовБрокераВУ(Отказ)
            |                       |
            |                       +---> Формирование проводок по переоценке счетов брокера
            |       |
            |       +---> Движения.Хозрасчетный.Записывать = ИСТИНА
            |
            v
    [Шаг 8: Формирование движений по управленческому учету (УУ)]
            |
            +---> УправленческийУчет(Отказ)
            |       |
            |       +---> Если ТипПортфеля = ИнвестицииДоПогашения:
            |               |
            |               +---> УУ_ЦенныеБумагиHTM(Отказ)
            |                       |
            |                       +---> Формирование движений по регистру УУ_ЦенныеБумагиHTM
            |               |
            |               +---> УУ_НКДПоЦеннымБумагамHTM(Отказ)
            |                       |
            |                       +---> Формирование движений по регистру УУ_НКДПоЦеннымБумагамHTM
            |       |
            |       +---> Иначе:
            |               |
            |               +---> ПодготовитьТаблицуОстатковАктива_УУ(Отказ)
            |               |
            |               +---> СтоимостьАктивовУправленческий(Отказ)
            |                       |
            |                       +---> Если ВидОперации = Поступление:
            |                               |
            |                               +---> Движение = Движения.СтоимостьАктивовУправленческий.ДобавитьПриход()
            |                               |
            |                               +---> Заполнение: Период, ДоговорДУ, Актив, Количество, Валюта, Стоимость
            |                       |
            |                       +---> Если ВидОперации = Продажа:
            |                               |
            |                               +---> Движение = Движения.СтоимостьАктивовУправленческий.ДобавитьРасход()
            |                               |
            |                               +---> Заполнение: Период, ДоговорДУ, Актив, Количество, Валюта, Стоимость
            |                       |
            |                       +---> Движения.СтоимостьАктивовУправленческий.Записывать = ИСТИНА
            |               |
            |               +---> НачисленныйКупонныйДоходУправленческий(Отказ)
            |                       |
            |                       +---> Если ВидОперации = Поступление:
            |                               |
            |                               +---> Движение = Движения.НачисленныйКупонныйДоходУправленческий.ДобавитьПриход()
            |                               |
            |                               +---> Заполнение: Период, ДоговорДУ, Актив, Партия, НКД
            |                       |
            |                       +---> Если ВидОперации = Продажа:
            |                               |
            |                               +---> Движение = Движения.НачисленныйКупонныйДоходУправленческий.ДобавитьРасход()
            |                               |
            |                               +---> Заполнение: Период, ДоговорДУ, Актив, Партия, НКД
            |                       |

7. КЛЮЧЕВЫЕ ОСОБЕННОСТИ ПРОВЕДЕНИЯ
================================================================================

    [1] Блокировки устанавливаются ПЕРЕД формированием движений]
            |
            +---> УстановитьБлокировку() вызывается ДО всех процедур формирования движений
            |
            +---> Блокируются:
                    - РегистрБухгалтерии.Хозрасчетный (по счетам активов и взаиморасчетов)
                    - РегистрНакопления.СтоимостьАктивовУправленческий (для УУ)
                    - Режим блокировки: Исключительный

    [2] Различная логика для Поступления и Продажи]
            |
            +---> Для Поступления:
                    - Формируются движения по поступлению активов
                    - Формируются движения по поступлению НКД
                    - Формируются движения по поступлению доп. расходов
                    - Формируются движения по зачету авансов
                    - Формируются движения по разблокировке ДС
            |
            +---> Для Продажи:
                    - Подготавливаются таблицы для расчета себестоимости
                    - Формируются движения по списанию активов
                    - Формируются движения по списанию переоценки
                    - Формируются движения по списанию доп. расходов
                    - Формируются движения по реализации
                    - Формируются движения по доходам от НКД
                    - Формируются движения по списанию НКД

    [3] Учет в разных разрезах]
            |
            +---> Бухгалтерский учет (БУ):
                    - Формируются проводки по РегистрБухгалтерии.Хозрасчетный
                    - Учитываются все счета бухгалтерского учета
            |
            +---> Управленческий учет (УУ):
                    - Формируются движения по РегистрНакопления.СтоимостьАктивовУправленческий
                    - Формируются движения по РегистрНакопления.НачисленныйКупонныйДоходУправленческий
                    - Формируются движения по РегистрНакопления.ДенежныеСредстваУправленческий
            |
            +---> Внутренний учет (ВУ):
                    - Формируются проводки по забалансовым счетам
                    - Учет активов на забалансовых счетах

    [4] Специальная обработка для облигаций]
            |
            +---> При поступлении:
                    - Формируются движения по поступлению НКД
            |
            +---> При продаже:
                    - Формируются движения по доходам от НКД
                    - Формируются движения по списанию НКД
                    - Формируются движения по отложенной выручке
            |
            +---> Для HTM портфеля:
                    - Используются специальные регистры УУ_ЦенныеБумагиHTM и УУ_НКДПоЦеннымБумагамHTM

    [5] Обработка плановых позиций]
            |
            +---> Если ПлановаяПозиция заполнена:
                    - Формируются движения по регистру ПлановыеПозиции
                    - Отражается фактическое исполнение плановой позиции

    [6] Расчет себестоимости при продаже]
            |
            +---> Вызывается ТаблицыПоПродажам_БУ():
                    - Получение остатков активов
                    - Расчет себестоимости по методу списания (ФИФО, ЛИФО, Средняя)
                    - Подготовка таблиц для формирования движений
