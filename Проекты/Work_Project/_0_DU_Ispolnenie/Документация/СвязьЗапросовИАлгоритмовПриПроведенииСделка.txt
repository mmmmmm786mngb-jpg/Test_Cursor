ОПИСАНИЕ: Данный документ содержит детальное описание всех запросов к базе данных,

          используются.

================================================================================
2. ДЕТАЛЬНОЕ ОПИСАНИЕ КАЖДОГО ЗАПРОСА
================================================================================

    [ЗАПРОС 1: Проверка корпоративных действий (акции)]
            |
            +---> ВЫЗЫВАЕТСЯ В: УстановитьПараметрыОблигации()
            |
            +---> УСЛОВИЕ: Если Актив = Акция ИЛИ Пай ПИФ
            |
            +---> ЦЕЛЬ: Проверить наличие начисленных дивидендов по акции
            |
            +---> ЗАПРОС:
                    |
                    ВЫБРАТЬ
                        КорпоративноеДействие.СуммаДивидендовНаОднуАкцию
                    ИЗ
                        Документ.КорпоративноеДействие КАК КорпоративноеДействие
                    ГДЕ
                        КорпоративноеДействие.Актив = &Актив
                        И КорпоративноеДействие.ДатаФиксацииРеестра >= &СрокПеререгистрации
                        И КорпоративноеДействие.ДатаФиксацииРеестра < &Дата
                        И КорпоративноеДействие.ВидОперации = НачислениеДивидендов
                        И КорпоративноеДействие.Проведен
            |
            +---> РЕЗУЛЬТАТ: Список документов корпоративных действий с дивидендами
            |
            +---> ИСПОЛЬЗОВАНИЕ:
                    |
                    +---> Для каждого найденного документа:
                            |
                            +---> Выводится предупреждение пользователю:
                                    "Требование по дивидендам по [Актив] под сделку [Ссылка].
                                     Сумма требования = [Сумма] [Валюта]"
            |
            +---> ВЛИЯНИЕ НА АЛГОРИТМ:
                    |
                    +---> НЕ влияет на формирование движений
                    |
                    +---> Только информационное сообщение пользователю

    [ЗАПРОС 2: Проверка купонных периодов (облигации)]
            |
            +---> ВЫЗЫВАЕТСЯ В: УстановитьПараметрыОблигации()
            |
            +---> УСЛОВИЕ: Если Актив = Облигация
            |
            +---> ЦЕЛЬ: Проверить наличие купонных периодов с фиксацией реестра
            |
            +---> ЗАПРОС:
                    |
                    ВЫБРАТЬ
                        КупонныеПериоды.ДатаФиксацииРеестраВладельцевЦБ,
                        КупонныеПериоды.Ссылка
                    ИЗ
                        Справочник.КупонныеПериоды КАК КупонныеПериоды
                    ГДЕ
                        КупонныеПериоды.Владелец = &Облигация
                        И КупонныеПериоды.ДатаФиксацииРеестраВладельцевЦБ >= &СрокПеререгистрации
                        И НЕ КупонныеПериоды.ПометкаУдаления
                        И КупонныеПериоды.ДатаФиксацииРеестраВладельцевЦБ < &Дата
            |
            +---> РЕЗУЛЬТАТ: Список купонных периодов с фиксацией реестра
            |
            +---> ИСПОЛЬЗОВАНИЕ:
                    |
                    +---> Для каждого найденного купонного периода:
                            |
                            +---> Рассчитывается НКД на дату фиксации реестра
                            |
                            +---> Выводится предупреждение пользователю:
                                    "Требование по купону по [Актив] под сделку [Ссылка].
                                     Сумма требования = [НКД] [Валюта]"
            |
            +---> ВЛИЯНИЕ НА АЛГОРИТМ:
                    |
                    +---> НЕ влияет на формирование движений
                    |
                    +---> Только информационное сообщение пользователю

    [ЗАПРОС 3: Получение суммы ОНВ]
            |
            +---> ВЫЗЫВАЕТСЯ В: ПолучитьСуммуОНВ()
            |
            +---> ВЫЗЫВАЕТ: УстановитьДополнительныеПараметрыПроведения()
            |
            +---> ЦЕЛЬ: Получить сумму обязательств на выплату (ОНВ) по договору ДУ
            |
            +---> ЗАПРОС: (детали запроса не показаны в коде, но используется)
            |
            +---> РЕЗУЛЬТАТ: ТаблицаОНВ с суммой ОНВ
            |
            +---> ИСПОЛЬЗОВАНИЕ:
                    |
                    +---> Сохраняется в переменную ТаблицаОНВ
                    |
                    +---> Используется в дальнейших расчетах при формировании движений
            |
            +---> ВЛИЯНИЕ НА АЛГОРИТМ:
                    |
                    +---> Используется при расчете сумм для формирования движений

    [ЗАПРОС 4: Подготовка таблиц для зачета авансов]
            |
            +---> ВЫЗЫВАЕТСЯ В: ТаблицыАванса()
            |
            +---> ВЫЗЫВАЕТ: СформироватьДвиженияЗачетАвансов()
            |
            +---> ЦЕЛЬ: Подготовить таблицы данных документа для зачета авансов
            |
            +---> ЗАПРОС (пакетный):
                    |
                    [1] ВЫБРАТЬ данные по активам из документа Сделка
                        ПОМЕСТИТЬ ТаблицаДанныхПоАктивам
                    |
                    [2] ВЫБРАТЬ данные по доп. расходам из документа Сделка
                        ПОМЕСТИТЬ ТаблицаДанныхПоДопРасходам
                    |
                    [3] ВЫБРАТЬ данные для взаиморасчетов
                        ИЗ ТаблицаДанныхПоАктивам
                    |
                    [4] ВЫБРАТЬ данные для НКД
                        ИЗ ТаблицаДанныхПоАктивам
                    |
                    [5] ВЫБРАТЬ данные для доп. расходов
                        ИЗ ТаблицаДанныхПоДопРасходам
                    |
                    [6] ВЫБРАТЬ данные для зачета авансов по документу
                        ИЗ Документ.Сделка.ЗачетАвансов
            |
            +---> РЕЗУЛЬТАТ: Структура с таблицами:
                    |
                    +---> ТаблицаДокумента - данные документа для взаиморасчетов
                    |
                    +---> ТаблицаДокументыАвансов - данные для зачета авансов
            |
            +---> ИСПОЛЬЗОВАНИЕ:
                    |
                    +---> Передается в ПодготовитьТаблицуВзаиморасчетовЗачетАвансов()
                    |
                    +---> Используется для формирования движений по зачету авансов
            |
            +---> ВЛИЯНИЕ НА АЛГОРИТМ:
                    |
                    +---> КРИТИЧЕСКИ ВАЖНО: Без этого запроса невозможно сформировать
                            движения по зачету авансов
                    |
                    +---> Определяет суммы и параметры для зачета авансов

    [ЗАПРОС 5: Получение остатков авансов]
            |
            +---> ВЫЗЫВАЕТСЯ В: ПолучитьАвансы()
            |
            +---> ВЫЗЫВАЕТ: СформироватьДвиженияЗачетАвансов()
            |
            +---> ЦЕЛЬ: Получить остатки по счетам авансов для зачета
            |
            +---> ЗАПРОС (пакетный):
                    |
                    [1] ВЫБРАТЬ остатки по счетам авансов
                        ПОМЕСТИТЬ ОстаткиАвансов
                        ИЗ РегистрБухгалтерии.Хозрасчетный.Остатки()
                        ГДЕ Счет В (&СчетаАвансов)
                            И Контрагент В (&Контрагент)
                            И ДоговорКонтрагента В (&ДоговорКонтрагента)
                            И Валюта = &Валюта
                    |
                    [2] ВЫБРАТЬ итоговые суммы авансов
                        ИЗ ОстаткиАвансов
                        СГРУППИРОВАТЬ ПО Контрагент, ДоговорКонтрагента, Валюта, Счет
            |
            +---> РЕЗУЛЬТАТ: Таблица ОстаткиАвансов с остатками по авансам
            |
            +---> ИСПОЛЬЗОВАНИЕ:
                    |
                    +---> Передается в ПодготовитьТаблицуВзаиморасчетовЗачетАвансов()
                    |
                    +---> Используется для расчета сумм зачета авансов
                    |
                    +---> Определяет, какие авансы можно зачесть
            |
            +---> ВЛИЯНИЕ НА АЛГОРИТМ:
                    |
                    +---> КРИТИЧЕСКИ ВАЖНО: Без этого запроса невозможно определить
                            суммы для зачета авансов
                    |
                    +---> Определяет суммы проводок по зачету авансов
                    |
                    +---> Влияет на суммы взаиморасчетов

    [ЗАПРОС 6: Получение заблокированных ДС]
            |
            +---> ВЫЗЫВАЕТСЯ В: СформироватьДвиженияРазблокировкаДС()
            |
            +---> ВЫЗЫВАЕТ: БухгалтерскийУчет() -> СформироватьДвиженияРазблокировкаДС()
            |
            +---> УСЛОВИЕ: Только при поступлении
            |
            +---> ЦЕЛЬ: Получить сумму заблокированных денежных средств по бизнес-процессу
            |
            +---> ЗАПРОС:
                    |
                    ВЫБРАТЬ
                        ХозрасчетныйОстатки.Валюта,
                        ХозрасчетныйОстатки.СуммаОстатокДт КАК Сумма,
                        ХозрасчетныйОстатки.ВалютнаяСуммаОстатокДт КАК ВалютнаяСумма,
                        ХозрасчетныйОстатки.Субконто1,
                        ХозрасчетныйОстатки.Субконто2,
                        ХозрасчетныйОстатки.Субконто3
                    ИЗ
                        РегистрБухгалтерии.Хозрасчетный.Остатки(
                            &Период,
                            Счет = БлокированиеДСПодСделку,
                            ,
                            ДоговорДУ = &ДоговорДУ
                                И Валюта = &Валюта
                                И Субконто1 = &Депозитарий
                                И Субконто2 = &Договор
                                И Субконто3 = &ДокументРасчетов)
            |
            +---> РЕЗУЛЬТАТ: Остатки по счету блокирования ДС
            |
            +---> ИСПОЛЬЗОВАНИЕ:
                    |
                    +---> Если остаток найден:
                            |
                            +---> Формируется проводка:
                                    Дт: СчетУчетаРасчетовСКонтрагентом
                                    Кт: БлокированиеДСПодСделку
                            |
                            +---> Сумма = остаток (или часть остатка при частичном исполнении)
            |
            +---> ВЛИЯНИЕ НА АЛГОРИТМ:
                    |
                    +---> КРИТИЧЕСКИ ВАЖНО: Без этого запроса невозможно разблокировать ДС
                    |
                    +---> Определяет сумму проводки по разблокировке ДС
                    |
                    +---> Влияет на остатки по счету блокирования ДС

    [ЗАПРОС 7: Получение остатков активов для списания (при продаже)]
            |
            +---> ВЫЗЫВАЕТСЯ В: ТаблицыПоПродажам_БУ()
            |
            +---> ВЫЗЫВАЕТ: БухгалтерскийУчет() -> ТаблицыПоПродажам_БУ()
            |
            +---> УСЛОВИЕ: Только при продаже
            |
            +---> ЦЕЛЬ: Получить остатки активов для расчета себестоимости списания
            |
            +---> ЗАПРОС (пакетный, очень сложный):
                    |
                    [1] ВЫБРАТЬ остатки по счетам активов
                        ПОМЕСТИТЬ ВТ_ХозрасчетныйОстатки
                        ИЗ РегистрБухгалтерии.Хозрасчетный.Остатки()
                        ГДЕ Счет В (&СчетаОстатков)
                            И Субконто1 = &АктивОбъект
                            И ДоговорДУ = &ДоговорДУ
                    |
                    +---> ОПИСАНИЕ СЧЕТОВ В МАССИВЕ &СчетаОстатков:
                            |
                            +---> [1] СчетУчетаАктива
                            |       |
                            |       +---> ИСТОЧНИК: Реквизит шапки документа Сделка
                            |       |
                            |       +---> ОПИСАНИЕ: Основной счет учета актива (тело)
                            |       |
                            |       +---> ПРИМЕРЫ ЗНАЧЕНИЙ:
                            |               |
                            |               +---> ПланыСчетов.Хозрасчетный.ОблигацииТело
                            |               |       (для облигаций)
                            |               |
                            |               +---> ПланыСчетов.Хозрасчетный.АкцииТело
                            |               |       (для акций)
                            |               |
                            |               +---> Другие счета учета активов в зависимости
                            |                       от типа актива и настроек договора ДУ
                            |
                            +---> [2] СчетУчетаАктиваПереоценка
                            |       |
                            |       +---> ИСТОЧНИК: Вычисляется динамически в функции
                            |               ТаблицыПоПродажам_БУ()
                            |       |
                            |       +---> ЛОГИКА ОПРЕДЕЛЕНИЯ:
                            |               |
                            |               +---> Если Актив = Облигация
                            |               |       И ТипПортфеля = ИнвестицииДоПогашения
                            |               |       И ВидОперации = Поступление:
                            |               |       |
                            |               |       +---> Счет = ПланыСчетов.Хозрасчетный.
                            |               |               ОблигацииУдерживаемыеДоПогашенияКорректировка
                            |               |
                            |               +---> Иначе:
                            |                       |
                            |                       +---> КодСчетаПереоценки = 
                            |                               СчетУчетаАктива.Родитель.Код + ".2"
                            |                       |
                            |                       +---> Счет = ПС.НайтиПоКоду(КодСчетаПереоценки)
                            |                       |
                            |                       +---> ПРИМЕРЫ:
                            |                               |
                            |                               +---> Если СчетУчетаАктива = 58.02.1
                            |                                       (ОблигацииТело)
                            |                                       |
                            |                                       +---> СчетУчетаАктиваПереоценка = 58.02.2
                            |                                               (ОблигацииПереоценка)
                            |                               |
                            |                               +---> Если СчетУчетаАктива = 58.01.1
                            |                                       (АкцииТело)
                            |                                       |
                            |                                       +---> СчетУчетаАктиваПереоценка = 58.01.2
                            |                                               (АкцииПереоценка)
                            |       |
                            |       +---> ОПИСАНИЕ: Счет для учета переоценки актива
                            |
                            +---> [3] ПланыСчетов.Хозрасчетный.ЧПО
                            |       |
                            |       +---> ИСТОЧНИК: Добавляется только при выполнении условия
                            |       |
                            |       +---> УСЛОВИЕ ДОБАВЛЕНИЯ:
                            |               |
                            |               +---> ЭтоОблигация = Истина
                            |               |
                            |               +---> БУ = Истина (бухгалтерский учет включен)
                            |       |
                            |       +---> ОПИСАНИЕ: Счет для учета частичного погашения
                            |               облигаций (ЧПО - Частичное Погашение Облигаций)
                            |       |
                            |       +---> НАЗНАЧЕНИЕ: Используется для учета остатков по
                            |               частично погашенным облигациям
                            |
                            +---> ИТОГО: В массиве СчетаОстатков может быть:
                                    |
                                    +---> Минимум 2 счета:
                                            - СчетУчетаАктива
                                            - СчетУчетаАктиваПереоценка
                                    |
                                    +---> Максимум 3 счета (если облигация и БУ):
                                            - СчетУчетаАктива
                                            - СчетУчетаАктиваПереоценка
                                            - ЧПО
                    |
                    [2] ВЫБРАТЬ остатки по телу активов
                        ПОМЕСТИТЬ ВТ_ОстаткиТело
                        ИЗ ВТ_ХозрасчетныйОстатки
                        ГДЕ Счет = &СчетУчетаАктива
                    |
                    [3] ВЫБРАТЬ остатки по переоценке
                        ПОМЕСТИТЬ ВТ_ОстаткиПереоценка
                        ИЗ ВТ_ХозрасчетныйОстатки
