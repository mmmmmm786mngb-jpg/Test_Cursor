│  │  │  │ → Скорость падает                                     │ │   │   │
│  │  │  │ → Уменьшить ЦелевоеКоличествоАктивных                 │ │   │   │

1. Вычисление целевого веса (Q1 + 1.5×IQR):
   - Сортировка весов договоров по возрастанию
   - Q1 = 25-й процентиль
   - Q3 = 75-й процентиль
   - IQR = Q3 - Q1
   - ЦелевойВес = Q1 + 1.5 × IQR

2. Распределение:
   - Большие договоры (Вес >= ЦелевойВес):
     → Один договор на поток
   - Малые договоры (Вес < ЦелевойВес):
     → Объединение в потоки до достижения ЦелевойВес

┌─────────────────────────────────────────────────────────────────────────────┐
│  АЛГОРИТМ ДИНАМИЧЕСКОГО УПРАВЛЕНИЯ ПОТОКАМИ                                 │
└─────────────────────────────────────────────────────────────────────────────┘

Период проверки: 60 секунд

Формула изменения количества потоков:
  ПроцентИзменения = (СкоростьТекущая - СкоростьПредыдущая) / СкоростьПредыдущая × 100
  ИзменениеПотоков = Цел(ПроцентИзменения / 20)
  
  ЕСЛИ Скорость растет:
    НовоеКоличество = Мин(Текущее + ИзменениеПотоков, Базовое × 2)
    НоваяПауза = Макс(Текущая - ИзменениеПаузы, 0.1)
    
  ЕСЛИ Скорость падает:
    НовоеКоличество = Макс(Текущее - ИзменениеПотоков, Базовое)
    НоваяПауза = Мин(Текущая + ИзменениеПаузы, 1.0)

Ограничения:
  - Минимум потоков: N (базовое количество)
  - Максимум потоков: 2N (удвоенное базовое количество)
  - Минимум паузы: 0.1 сек
  - Максимум паузы: 1.0 сек
