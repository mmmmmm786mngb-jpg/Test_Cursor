## Важно помнить

1. **Функция `РаспределитьЗадачиПоПотокам` теперь возвращает структуру**, а не таблицу:
   ```bsl
   СтатистикаРаспределения = РаспределитьЗадачиПоПотокам(...);
   Потоки = СтатистикаРаспределения.Потоки;
   ```

2. **Начальная пауза = 2.0 секунды** (было 1.0)

3. **Потоков создается больше** чем указано в `КоличествоПотоков`, но одновременно работает только N

4. **Удалить все строки** с комментарием `!!! ВЫПИЛИТЬ ПЕРЕД ПЕРЕНОСОМ`
