# Диаграмма работы обработки "внИсполнениеСделокТ+2_ДУ"

## Общая схема вызова и выполнения

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    РЕГЛАМЕНТНОЕ ЗАДАНИЕ                                 │
│              "ЗапускДополнительныхОбработок"                            │
│                                                                         │
│  Расписание: по настройке в справочнике                                │
│  Метод: ДополнительныеОтчетыИОбработки.                                │
│          ВыполнитьОбработкуПоРегламентномуЗаданию()                     │
└────────────────────────────┬────────────────────────────────────────────┘
                             │
                             │ Параметры:
                             │ - ВнешняяОбработка (ссылка из справочника)
                             │ - ИдентификаторКоманды
                             │ - ПараметрыДополнительнойОбработки
                             │   (из ХранилищеНастроек)
                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│         МОДУЛЬ: ДополнительныеОтчетыИОбработки                          │
│                                                                         │
│  1. ВыполнитьОбработкуПоРегламентномуЗаданию()                          │

│     └─ ВыполнитьОбработкуНепосредственно()                              │
│                                                                         │
│  2. ВыполнитьОбработкуНепосредственно()                                 │
│     ├─ ПолучитьОбъектВнешнейОбработки()                                 │
│     ├─ НастройкиОбработки() → ХранилищеНастроек                         │
│     └─ ВыполнитьКомандуОбработки()                                      │
│                                                                         │
│  3. ВыполнитьКомандуОбработки()                                         │
│     └─ ВнешняяОбработка.ВыполнитьКоманду()                              │
└────────────────────────────┬────────────────────────────────────────────┘
                             │
                             │ Вызов команды обработки
                             │ (ИдентификаторКоманды)
                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│         ВНЕШНЯЯ ОБРАБОТКА: внИсполнениеСделокТ+2_ДУ                     │
│                                                                         │
│  Модуль: ObjectModule.bsl                                               │
│                                                                         │
│  ВыполнитьКоманду(ИдентификаторКоманды, ПараметрыВыполненияКоманды)    │
│  ├─ Определение команды:                                                │
│  │   ├─ "ФоновоеВыполнение_ПотоковоеИсполнениеСделок"                   │
│  │   │   └─ ДатаИсполнения = ТекущаяДата()                             │
│  │   │   └─ ВыполнитьСделкиПотоки(Параметры, "")                       │
│  │   │                                                                  │
│  │   ├─ "ФоновоеВыполнениеПотоковое_ТМинус1"                            │
│  │   │   └─ ДатаИсполнения = ТекущаяДата() - 86400                     │
│  │   │   └─ ВыполнитьСделкиПотоки(Параметры, "На Т-1")                 │
│  │   │                                                                  │
│  │   └─ "ФоновоеВыполнение_ПотоковоеИсполнениеСделокПул"               │
│  │       └─ ДатаИсполнения = НачалоДня(ТекущаяДата())                  │
│  │       └─ ВыполнитьСделкиПотоки(Параметры, "Пул")                     │
│  │                                                                      │
│  └─ УстановитьНастройки()                                               │
│      └─ УстановитьПользовательскиеНастройки()                           │
│          ├─ ПочтовыйЛогин                                                │
│          ├─ СписокРассылки                                               │
│          ├─ Пулы                                                         │
│          ├─ РежимЗагрузки                                                │
│          └─ КоличествоПотоков                                            │
└────────────────────────────┬────────────────────────────────────────────┘

                             │ ВыполнитьСделкиПотоки()

┌─────────────────────────────────────────────────────────────────────────┐
│  ВыполнитьСделкиПотоки(ПараметрыВыполненияКоманды, ОпределениеЗапуска)│
│                                                                         │
│  1. УстановитьНастройки()                                               │
│                                                                         │
│  2. РассчитатьКомиссиюОбороотовВБизнесПроцессах()                       │
│     ├─ Получение брокеров с флагом "Расчет комиссии от оборотов"       │
│     ├─ Получение сделок за день                                        │
│     ├─ Расчет общей комиссии по договору брокера                       │
│     └─ Распределение комиссии по сделкам                                │
│                                                                         │
│  3. Подготовка списка пулов (если ОпределениеЗапуска = "Пул")          │
│     └─ СписокПулов = Пулы.ВыгрузитьКолонку("Пул")                      │
│                                                                         │
│  4. ВыполнитьСделкиВПотоках(Истина, Отказ, Комментарий, СписокПулов)   │
│                                                                         │
│  5. Расчет продолжительности выполнения                                │
│                                                                         │
│  6. Создание задачи интеграции                                         │
│                                                                         │
│  7. Отправка email-рассылки (если настроено)                           │
│                                                                         │
│  8. Запись в журнал регистрации                                        │
└────────────────────────────┬────────────────────────────────────────────┘
                             │
                             │ ВыполнитьСделкиВПотоках()
                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  ВыполнитьСделкиВПотоках(ПроверкаВыполнения, Отказ, Комментарий, Пул)  │
│                                                                         │
│  1. РаспределитьЗадачиПоПотокам(ДатаИсполнения, КоличествоПотоков, Пул) │
│     ├─ Запрос к базе: получение договоров ДУ с количеством задач        │
│     │   ├─ Фильтр по дате исполнения                                   │
│     │   ├─ Фильтр по типу клиента (если РежимЗагрузки задан)           │
│     │   └─ Фильтр по пулам (если Пул задан)                           │
│     │                                                                  │
│     ├─ Сортировка по количеству задач (УБЫВ)                           │
│     │                                                                  │
│     └─ Распределение договоров по потокам:                             │
│         └─ Алгоритм "наименее загруженный поток"                        │
│                                                                         │
│  2. Создание фоновых заданий для каждого потока:                       │
│     Для каждого потока (0..КоличествоПотоков-1):                       │
│     ├─ ПараметрыЗадания.ДатаИсполнения = ДатаИсполнения                │
│     ├─ ПараметрыЗадания.СписокДоговор = Потоки[Сч].МассивДоговоров     │
│     └─ ФоновыеЗадания.Выполнить(                                       │
│            "VTB_ОбщийМодуль.ВыполнитьИсполнениеСделокПоСпискуДоговорДУ",│
│            ПараметрыЗадания)                                            │
│                                                                         │
│  3. Ожидание завершения всех заданий (если ПроверкаВыполнения = Истина)│
│     ├─ Цикл проверки состояния заданий                                 │
│     ├─ Сбор сообщений из завершенных заданий                           │
│     └─ Формирование итогового комментария                              │
└────────────────────────────┬────────────────────────────────────────────┘
                             │
                             │ Фоновое задание
                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  КОНФИГУРАЦИЯ: VTB_ОбщийМодуль                                          │
│                                                                         │
│  ВыполнитьИсполнениеСделокПоСпискуДоговорДУ(ПараметрыЗадания)          │
│  ├─ ДатаИсполнения = ПараметрыЗадания.ДатаИсполнения                   │
│  ├─ СписокДоговор = ПараметрыЗадания.СписокДоговор                     │
│  │                                                                      │
│  ├─ БизнесПроцессы.СделкиTn.ИсполнениеПлановойПозиции(                  │
│  │      ДатаИсполнения, Отказ, ТекстОтказа, СписокДоговор)             │
│  │   ├─ ПолучитьОткрытыеЗадачиПоСделкеTn(Дата, СписокДоговоровДУ)      │
│  │   │   └─ Запрос: задачи по сделкам T+n на дату                       │
│  │   │       ├─ Фильтр по дате исполнения                               │
│  │   │       ├─ Фильтр по списку договоров ДУ                           │
│  │   │       └─ Сортировка: юр.лица первыми, затем по дате             │
│  │   │                                                                  │
│  │   └─ Выполнение задач:                                               │
│  │       Для каждой задачи:                                             │
│  │       ├─ ПолучитьОбъект()                                            │
│  │       ├─ СинхронизоватьПредметПоЗадаче = Истина                      │
│  │       └─ ВыполнитьЗадачу()                                           │
│  │                                                                      │
│  └─ АвтоматическиВыполнитьЗадачиПоСделкеРЕПО(                           │
│         Дата, Отказ, ТекстОтказа, СписокДоговор)                       │
│      ├─ ПолучитьОткрытыеЗадачиПоСделкеРЕПО(Дата, СписокДоговор)        │
│      │   └─ Запрос: задачи по сделкам РЕПО на дату                     │
│      │                                                                  │
│      └─ Выполнение задач в 3 этапа:                                     │
│          ├─ Этап 1: ПерваяЧастьРЕПО                                      │
│          ├─ Этап 2: ВтораяЧастьРЕПО (если была ПерваяЧасть)            │
│          └─ Этап 3: Остальные задачи (если была ВтораяЧасть)           │
└─────────────────────────────────────────────────────────────────────────┘
```

## Детальная схема распределения задач по потокам

```
┌─────────────────────────────────────────────────────────────────────────┐
│  РаспределитьЗадачиПоПотокам(ДатаИсполнения, ЧислоПотоков, Пул)         │
│                                                                         │
│  ШАГ 1: Инициализация потоков                                          │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ Для каждого потока (0..ЧислоПотоков-1):             │               │
│  │ ├─ НомерПотока = Сч                                  │               │
│  │ ├─ ТекущаяЗагрузка = 0                               │               │
│  │ └─ МассивДоговоров = Новый Массив                   │               │
│  └─────────────────────────────────────────────────────┘               │
│                                                                         │
│  ШАГ 2: Получение списка договоров с задачами                          │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ Запрос к базе:                                       │               │
│  │ ├─ Группировка по ДоговорДУ                          │               │
│  │ ├─ Подсчет КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Ссылка) задач       │               │
│  │ ├─ Фильтры:                                          │               │
│  │ │   ├─ Дата исполнения МЕЖДУ начало/конец дня        │               │
│  │ │   ├─ Тип клиента (если РежимЗагрузки задан)        │               │
│  │ │   └─ Пул (если задан)                              │               │
│  │ └─ Сортировка: Количество задач УБЫВ                 │               │
│  └─────────────────────────────────────────────────────┘               │
│                                                                         │
│  ШАГ 3: Распределение по алгоритму "наименее загруженный"              │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ Для каждого договора из списка:                     │               │
│  │ ├─ ОпределитьНаименееЗагруженныйПоток(Потоки)       │               │
│  │ │   └─ Сортировка по ТекущаяЗагрузка ВОЗР           │               │
│  │ │   └─ Возврат Потоки[0]                            │               │
│  │ │                                                    │               │
│  │ ├─ НаименееЗагруженныйПоток.ТекущаяЗагрузка +=      │               │
│  │ │     КоличествоЗадач                                │               │
│  │ └─ НаименееЗагруженныйПоток.МассивДоговоров.        │               │
│  │     Добавить(ДоговорДУ)                             │               │
│  └─────────────────────────────────────────────────────┘               │
│                                                                         │
│  РЕЗУЛЬТАТ: ТаблицаЗначений "Потоки"                                   │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ Поток[0]: МассивДоговоров = [Договор1, Договор2...] │               │
│  │ Поток[1]: МассивДоговоров = [Договор3, Договор4...] │               │
│  │ ...                                                   │               │
│  │ Поток[N]: МассивДоговоров = [ДоговорX, ДоговорY...]  │               │
│  └─────────────────────────────────────────────────────┘               │
└─────────────────────────────────────────────────────────────────────────┘
```

## Схема работы с настройками

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    ХРАНИЛИЩЕ НАСТРОЕК                                   │
│         (Справочник.ДополнительныеОтчетыИОбработки.                     │
│          ХранилищеНастроек)                                              │
│                                                                         │
│  Структура "Значения":                                                  │
│  ├─ ПочтовыйЛогин → Справочник.УчетныеЗаписиЭлектроннойПочты            │
│  ├─ СписокРассылки → ТаблицаЗначений (XML)                              │
│  │   ├─ ПочтовыйЯщик (Строка)                                           │
│  │   └─ Представление (Строка)                                           │
│  │                                                                      │
│  ├─ Пулы → ТаблицаЗначений (XML)                                        │
│  │   └─ Пул → Справочник.Пул                                            │
│  │                                                                      │
│  ├─ РежимЗагрузки → Число (0, 1, 2)                                     │
│  │   ├─ 0 = Все клиенты                                                 │
│  │   ├─ 1 = Только физ.лица                                            │
│  │   └─ 2 = Только юр.лица                                              │
│  │                                                                      │
│  └─ КоличествоПотоков → Число (1..8)                                     │
└────────────────────────────┬────────────────────────────────────────────┘
                             │
                             │ УстановитьНастройки()
                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  УстановитьПользовательскиеНастройки(Настройки)                         │
│                                                                         │
│  ├─ ПочтовыйЛогин = Настройки.Значения.ПочтовыйЛогин                    │
│  │                                                                      │
│  ├─ СписокРассылки.Загрузить(                                           │
│  │      XMLЗначение(Настройки.Значения.СписокРассылки))                 │
│  │                                                                      │
│  ├─ Пулы.Загрузить(                                                     │
│  │      XMLЗначение(Настройки.Значения.Пулы))                           │
│  │                                                                      │
│  ├─ РежимЗагрузки = Настройки.Значения.РежимЗагрузки                    │
│  │                                                                      │
│  └─ КоличествоПотоков = Настройки.Значения.КоличествоПотоков            │
└─────────────────────────────────────────────────────────────────────────┘
```

## Схема выполнения сделок в конфигурации

```
┌─────────────────────────────────────────────────────────────────────────┐
│  БизнесПроцессы.СделкиTn.ИсполнениеПлановойПозиции()                    │
│                                                                         │
│  ЭТАП 1: Получение задач                                                │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ ПолучитьОткрытыеЗадачиПоСделкеTn(Дата, СписокДУ)    │               │
│  │                                                      │               │
│  │ Запрос:                                              │               │
│  │ ├─ Задача.ВнебиржеваяСделка                         │               │
│  │ ├─ Фильтры:                                         │               │
│  │ │   ├─ ПометкаУдаления = ЛОЖЬ                        │               │
│  │ │   ├─ АвтоматическоеВыполнениеЗадач = ИСТИНА       │               │
│  │ │   ├─ Выполнена = ЛОЖЬ                             │               │
│  │ │   ├─ СрокИсполнения МЕЖДУ начало/конец дня        │               │
│  │ │   ├─ БизнесПроцесс = СделкиTn                     │               │
│  │ │   └─ ДоговорДУ В (СписокДоговоровДУ)              │               │
│  │ │                                                    │               │
│  │ └─ Сортировка:                                       │               │
│  │     ├─ ЭтоЮЛ (юр.лица первыми) УБЫВ                 │               │
│  │     ├─ Дата                                          │               │
│  │     └─ Регистратор                                   │               │
│  └─────────────────────────────────────────────────────┘               │
│                                                                         │
│  ЭТАП 2: Выполнение задач (первый проход)                              │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ Для каждой задачи:                                   │               │
│  │ ├─ Если ТочкаМаршрута = ОткрытиеПлановойПозиции      │               │
│  │ │   └─ ЕстьОткрытиеПлановойПозиции = Истина          │               │
│  │ │                                                    │               │
│  │ ├─ ТекОбъект = Задача.Ссылка.ПолучитьОбъект()        │               │
│  │ ├─ ТекОбъект.СинхронизоватьПредметПоЗадаче = Истина │               │
│  │ └─ ТекОбъект.ВыполнитьЗадачу()                       │               │
│  └─────────────────────────────────────────────────────┘               │
│                                                                         │
│  ЭТАП 3: Повторное выполнение (если было ОткрытиеПлановойПозиции)      │
│  ┌─────────────────────────────────────────────────────┐               │
│  │ Если ЕстьОткрытиеПлановойПозиции:                    │               │
│  │ ├─ ПолучитьОткрытыеЗадачиПоСделкеTn() (повторно)     │               │
│  │ └─ Выполнить все задачи еще раз                      │               │
│  └─────────────────────────────────────────────────────┘               │
└─────────────────────────────────────────────────────────────────────────┘
```

## Схема email-рассылки

```
┌─────────────────────────────────────────────────────────────────────────┐
│  Отправка email-рассылки (в ВыполнитьСделкиПотоки)                      │
│                                                                         │
│  УСЛОВИЕ:                                                               │
│  ├─ СписокРассылки.Количество() > 0                                    │
│  └─ НЕ ПочтовыйЛогин.Пустая()                                           │
│                                                                         │
│  ФОРМИРОВАНИЕ ПИСЬМА:                                                   │
│  ├─ Тема:                                                               │
│  │   ├─ Префикс: "{OK} " или "{FAIL} " (по флагу Отказ)                │
│  │   ├─ "Аванкор ДУ: Фоновое исполнение сделок T+n                     │
│  │   │   (Потоковое выполнение) [ОпределениеЗапуска]                    │
│  │   │   ([Дата и время])"                                              │
│  │   └─ ПропискаРассылки("r2.1"|"r2.2"|"r2.3")                          │
│  │                                                                      │
│  ├─ Тело:                                                               │
│  │   ├─ Статус выполнения (успешно/ошибка)                             │
│  │   ├─ Режим загрузки (если задан)                                     │
│  │   ├─ Начало выполнения                                              │
│  │   ├─ Конец выполнения                                                │
│  │   ├─ Продолжительность (часы:минуты:секунды)                        │
│  │   └─ КомментарийПотоки (сообщения из заданий)                        │
│  │                                                                      │
│  ├─ Кому:                                                               │
│  │   └─ Массив структур из СписокРассылки:                              │
│  │       ├─ Адрес = ПочтовыйЯщик                                        │
│  │       └─ Представление = Представление                               │
│  │                                                                      │
│  └─ Важность:                                                           │
│      ├─ Высокая (если Отказ = Истина)                                  │
│      └─ Обычная (если Отказ = Ложь)                                    │
│                                                                         │
│  ОТПРАВКА:                                                              │

│         ПочтовыйЛогин, ПараметрыПисьма)                                │

## Последовательность выполнения (временная диаграмма)

```
ВРЕМЯ    │ ДЕЙСТВИЕ
─────────┼─────────────────────────────────────────────────────────────
T0       │ Регламентное задание "ЗапускДополнительныхОбработок"

         │   └─ ВыполнитьОбработкуНепосредственно()
         │
T1       │ Обработка: ВыполнитьКоманду()
         │   ├─ Определение команды
         │   ├─ Установка ДатаИсполнения

T2       │ ВыполнитьСделкиПотоки()

         │   └─ ВыполнитьСделкиВПотоках()
         │
T3       │ ВыполнитьСделкиВПотоках()
         │   ├─ РаспределитьЗадачиПоПотокам()

         │   │   └─ Распределение по потокам

         │       ├─ Поток 0: ФоновоеЗадание[0]

         │       └─ Поток N: ФоновоеЗадание[N]
         │
T4       │ Фоновые задания выполняются ПАРАЛЛЕЛЬНО:
         │   ├─ Задание[0] → VTB_ОбщийМодуль.ВыполнитьИсполнение...
         │   │   └─ БизнесПроцессы.СделкиTn.ИсполнениеПлановойПозиции()

         │   │

T5       │ Ожидание завершения всех заданий

         │   ├─ Создание задачи интеграции
         │   ├─ Отправка email-рассылки
         │   └─ Запись в журнал регистрации
         │

## Примечания

1. **Дата исполнения** устанавливается в зависимости от команды:
   - Основная команда: текущая дата
   - Т-1: вчерашняя дата
   - Пул: начало текущего дня

2. **Фильтрация по пулам**:
   - Основная команда и Т-1: только договоры БЕЗ пула
   - Команда Пул: только договоры С указанными пулами

3. **Многопоточность**: все потоки выполняются параллельно через фоновые задания

4. **Обработка ошибок**: ошибки собираются из всех потоков и включаются в итоговый комментарий

5. **Логирование**: все этапы выполнения логируются в журнал регистрации
