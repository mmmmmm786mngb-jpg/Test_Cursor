# Описание модулей с проблемами производительности

## Общая информация

Данный документ содержит подробное описание модулей конфигурации 1С:Enterprise, в которых обнаружены проблемы производительности при работе с документами сделок.

---

## 1. Документ.Сделка.МодульОбъекта

**Путь:** `Documents\Сделка\Ext\ObjectModule.bsl`  
**Тип:** Модуль объекта документа  
**Размер:** 5266 строк кода

### Назначение модуля

Модуль объекта документа "Сделка" отвечает за бизнес-логику обработки сделок с ценными бумагами. Модуль содержит:

- **Обработку операций с активами** - покупка, продажа, переоценка ценных бумаг
- **Учет взаиморасчетов** - зачет авансов, расчеты с контрагентами
- **Бухгалтерский и управленческий учет** - формирование проводок, расчет остатков
- **Работу с партиями** - списание по партиям (ФИФО, ЛИФО и т.д.)
- **Расчет НКД (накопленного купонного дохода)** - для облигаций
- **Переоценку активов** - валютная переоценка, переоценка по справедливой стоимости

### Основные функции модуля

#### Функция ПолучитьАвансы() (строка 863)

**Назначение:** Получение остатков авансов для зачета при проведении сделки  
**Проблемная строка:** 996 - `ОстаткиАвансов = Запрос.Выполнить().Выгрузить();`  
**Описание:** Выполняет сложный запрос к регистру бухгалтерии для получения остатков авансов по договору ДУ, контрагенту и валюте. Запрос включает группировку и фильтрацию по счетам авансов и дополнительных расходов.

#### Функция ТаблицыПоПродажам_БУ() (строка 1565)

**Назначение:** Формирование таблиц для проведения документа по продажам в бухгалтерском учете  
**Проблемная строка:** 1647 - `Результат = Запрос.ВыполнитьПакет();`  
**Описание:** Выполняет пакетный запрос для получения остатков активов, переоценки, списания активов. Используется при проведении документов продажи ценных бумаг. Запрос может включать расчет НКД для облигаций.

#### Процедура ПодготовитьТаблицуОстатковАктива_ВУ() (строка 1525)

**Назначение:** Подготовка таблицы остатков актива для валютного учета  
**Проблемная строка:** 1549 - `Результат = Запрос.Выполнить();`  
**Описание:** Получает остатки актива из регистра бухгалтерии для валютного учета. Используется при проверке наличия актива на балансе перед операцией.

#### Процедура ПодготовитьТаблицуОстатковАктива_УУ() (строка 1440)

**Назначение:** Подготовка таблицы остатков актива для управленческого учета  
**Проблемная строка:** 1467 - `ОстаткиАктива_УУ = Запрос.Выполнить().Выгрузить();`  
**Описание:** Получает остатки актива из регистра накопления "СтоимостьАктивовУправленческий". Используется для расчета остатков при операциях с активами в управленческом учете.

#### Функция ПолучитьСуммуОНВ() (строка 2057)

**Назначение:** Получение суммы ОНВ (обязательств по налогу на прибыль) для облигаций  
**Проблемная строка:** 2097 - `РезультаЗапроса = Запрос.Выполнить();`  
**Описание:** Выполняет запрос к регистру бухгалтерии для получения суммы обязательств по налогу на прибыль по облигациям. Используется при расчете налоговых обязательств.

### Контекст использования

Модуль вызывается при:

- Проведении документа "Сделка"
- Проверке возможности проведения
- Расчете остатков и сумм
- Формировании проводок

## 2. Документ.СделкаРЕПОВтораяНога.МодульОбъекта

**Путь:** `Documents\СделкаРЕПОВтораяНога\Ext\ObjectModule.bsl`  
**Тип:** Модуль объекта документа  
**Размер:** 4198 строк кода

### Назначение модуля

Модуль объекта документа "СделкаРЕПОВтораяНога" отвечает за обработку второй ноги сделок РЕПО (соглашения об обратном выкупе). Модуль содержит:

- **Обработку операций РЕПО** - прямая и обратная ноги сделок РЕПО
- **Учет обязательств** - отражение кредиторской и дебиторской задолженности
- **Расчет процентов по РЕПО** - начисление процентов по сделкам
- **Учет купонного дохода** - для облигаций в сделках РЕПО
- **Амортизацию комиссий** - распределение комиссий по периодам

### Основные функции модуля

#### Функция ТаблицыПоПродажам_БУ() (строка ~450)

**Назначение:** Формирование таблиц для проведения документа по продажам в бухгалтерском учете для РЕПО  
**Проблемная строка:** 519 - `Результат = Запрос.ВыполнитьПакет();`  
**Описание:** Выполняет пакетный запрос для получения остатков активов, переоценки, списания активов для второй ноги сделки РЕПО. Аналогично функции в документе "Сделка", но с учетом специфики РЕПО.

#### Процедура ПодготовитьТаблицуОстатковАктива_ВУ() (строка ~1250)

**Назначение:** Подготовка таблицы остатков актива для валютного учета  
**Проблемная строка:** 1282 - `Результат = Запрос.Выполнить();`  
**Описание:** Получает остатки актива из регистра бухгалтерии для валютного учета при операциях РЕПО. Используется при проверке наличия актива на балансе.

### Контекст использования

Модуль вызывается при:

- Проведении документа "СделкаРЕПОВтораяНога"
- Расчете обязательств по РЕПО
- Начислении процентов
- Формировании проводок по второй ноге РЕПО

## 3. РегистрСведений.ЗначенияПараметровДоговораДУ.МодульМенеджера

**Путь:** `InformationRegisters\ЗначенияПараметровДоговораДУ\Ext\ManagerModule.bsl`  
**Тип:** Модуль менеджера регистра сведений  
**Размер:** ~120 строк кода

### Назначение модуля

Модуль менеджера регистра сведений "ЗначенияПараметровДоговораДУ" отвечает за получение значений параметров договора доверительного управления на определенную дату.

### Основные функции модуля

#### Функция ЗначенияПараметровДоговораДУ() (строка 11)

**Назначение:** Получение значений параметров договора ДУ на дату  
**Проблемная строка:** 73 - `Результат = Запрос.Выполнить();`  
**Описание:** Выполняет запрос к регистру сведений для получения актуальных значений параметров договора ДУ на указанную дату. Параметры включают настройки учета, методы списания, счета учета и другие параметры, влияющие на проведение документов.

**Особенности:**

- Используется очень часто (6088 обращений по данным отладчика)
- Вызывается из множества мест при проведении документов
- Влияет на логику проведения всех документов по договору ДУ

### Контекст использования

Модуль вызывается при:

- Проведении любых документов по договору ДУ
- Получении настроек учета
- Проверке параметров договора
- Инициализации параметров проведения

## 4. ОбщийМодуль.VTB_ОбщийМодуль.Модуль

**Путь:** `CommonModules\VTB_ОбщийМодуль\Ext\Module.bsl`  
**Тип:** Общий модуль  
**Размер:** ~925 строк кода

### Назначение модуля

Общий модуль "VTB_ОбщийМодуль" содержит общие функции и процедуры для работы с системой. Модуль включает:

- **Работу с задачами** - получение открытых задач по сделкам
- **Работу с электронной почтой** - функции для работы с учетными записями
- **Служебные функции** - вспомогательные процедуры общего назначения

### Основные функции модуля

#### Функция ПолучитьОткрытыеЗадачиПоСделкеРЕПО() (строка 389)

**Назначение:** Получение списка открытых задач по сделкам РЕПО на дату  
**Проблемная строка:** 421 - `Результат = Запрос.Выполнить().Выгрузить();`  
**Описание:** Выполняет запрос к объекту "Задача" для получения списка открытых задач по внебиржевым сделкам РЕПО на указанную дату. Используется для контроля выполнения задач по сделкам.

**Особенности:**

- Вызывается редко (2 обращения), но занимает много времени на одно обращение (27.98% от общего времени)
- Используется в бизнес-процессах для контроля задач

### Контекст использования

Модуль вызывается при:

- Проверке открытых задач по сделкам РЕПО
- Контроле выполнения бизнес-процессов
- Работе с задачами в системе

## 5. БизнесПроцесс.СделкиTn.МодульМенеджера

**Путь:** `BusinessProcesses\СделкиTn\Ext\ManagerModule.bsl`  
**Тип:** Модуль менеджера бизнес-процесса  
**Размер:** 2923 строки кода

### Назначение модуля

Модуль менеджера бизнес-процесса "СделкиTn" отвечает за управление бизнес-процессом обработки внебиржевых сделок (Tn). Модуль включает:

- **Исполнение плановых позиций** - автоматическое выполнение задач по открытию и закрытию плановых позиций
- **Работу с задачами** - получение открытых задач по сделкам Tn
- **Управление бизнес-процессом** - выполнение шагов бизнес-процесса, обработка задач

### Основные функции модуля

#### Функция ПолучитьОткрытыеЗадачиПоСделкеTn() (строка 129)

**Назначение:** Получение списка открытых задач по внебиржевым сделкам Tn на дату  
**Проблемная строка:** 167 - `Результат = Запрос.Выполнить().Выгрузить();`  
**Описание:** Выполняет запрос к объекту "Задача" для получения списка открытых задач по внебиржевым сделкам Tn на указанную дату. Используется для контроля выполнения задач по сделкам и обработки плановых позиций.

**Особенности:**

- Аналогично функции `ПолучитьОткрытыеЗадачиПоСделкеРЕПО()` в модуле VTB_ОбщийМодуль
- Вызывается из процедуры `ИсполнениеПлановойПозиции()` для получения задач, требующих обработки
- Запрос фильтрует задачи по бизнес-процессу "СделкиTn", дате исполнения и договорам ДУ
- Используется при автоматическом исполнении плановых позиций

### Контекст использования

Модуль вызывается при:

- Автоматическом исполнении плановых позиций
- Получении открытых задач по сделкам Tn
- Обработке задач бизнес-процесса
- Контроле выполнения бизнес-процессов

## Общие замечания

### Проблемы производительности

Все обнаруженные проблемы связаны с выполнением запросов к базе данных:

1. **Отсутствие индексов** - возможно, запросы выполняются без использования индексов
2. **Большие объемы данных** - запросы обрабатывают большие объемы данных
3. **Частые обращения** - некоторые запросы вызываются очень часто
4. **Сложные запросы** - запросы содержат множественные соединения и группировки

### Рекомендации по оптимизации

1. **Анализ планов выполнения запросов** - проверить использование индексов
2. **Оптимизация запросов** - упростить структуру запросов, использовать временные таблицы
3. **Кэширование** - кэшировать результаты часто вызываемых запросов
4. **Параллельное выполнение** - оптимизировать алгоритм параллельного запуска запросов
