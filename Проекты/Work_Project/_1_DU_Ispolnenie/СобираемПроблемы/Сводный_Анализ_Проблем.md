# Сводный анализ проблем производительности

## Общая информация

Данный документ содержит сводную информацию о проблемных строках кода, обнаруженных отладчиком производительности 1С:Enterprise, с указанием их влияния на производительность системы.

---

## Проблемные строки по модулям

### 1. Документ.Сделка.МодульОбъекта

**Путь:** `Documents\Сделка\Ext\ObjectModule.bsl`

#### Строка 996 - Функция ПолучитьАвансы()

- **Код:** `ОстаткиАвансов = Запрос.Выполнить().Выгрузить();`
- **Описание:** Сложный запрос к регистру бухгалтерии для получения остатков авансов по договору ДУ, контрагенту и валюте. Включает группировку и фильтрацию по счетам авансов и дополнительных расходов.

#### Строка 1647 - Функция ТаблицыПоПродажам_БУ()

- **Код:** `Результат = Запрос.ВыполнитьПакет();`
- **Описание:** Пакетный запрос для получения остатков активов, переоценки, списания активов при проведении документов продажи ценных бумаг. Может включать расчет НКД для облигаций.

#### Строка 1549 - Процедура ПодготовитьТаблицуОстатковАктива_ВУ()

- **Код:** `Результат = Запрос.Выполнить();`
- **Описание:** Получение остатков актива из регистра бухгалтерии для валютного учета. Используется при проверке наличия актива на балансе перед операцией.

#### Строка 1467 - Процедура ПодготовитьТаблицуОстатковАктива_УУ()

- **Код:** `ОстаткиАктива_УУ = Запрос.Выполнить().Выгрузить();`
- **Описание:** Получение остатков актива из регистра накопления "СтоимостьАктивовУправленческий" для расчета остатков при операциях с активами в управленческом учете.

#### Строка 2097 - Функция ПолучитьСуммуОНВ()

- **Код:** `РезультаЗапроса = Запрос.Выполнить();`
- **Описание:** Запрос к регистру бухгалтерии для получения суммы обязательств по налогу на прибыль по облигациям. Используется при расчете налоговых обязательств.

### 2. Документ.СделкаРЕПОВтораяНога.МодульОбъекта

**Путь:** `Documents\СделкаРЕПОВтораяНога\Ext\ObjectModule.bsl`

#### Строка 519 - Функция ТаблицыПоПродажам_БУ()

- **Код:** `Результат = Запрос.ВыполнитьПакет();`
- **Описание:** Пакетный запрос для получения остатков активов, переоценки, списания активов для второй ноги сделки РЕПО. Аналогично функции в документе "Сделка", но с учетом специфики РЕПО.

#### Строка 1282 - Процедура ПодготовитьТаблицуОстатковАктива_ВУ()

- **Код:** `Результат = Запрос.Выполнить();`
- **Описание:** Получение остатков актива из регистра бухгалтерии для валютного учета при операциях РЕПО. Используется при проверке наличия актива на балансе.

---

### 3. РегистрСведений.ЗначенияПараметровДоговораДУ.МодульМенеджера

**Путь:** `InformationRegisters\ЗначенияПараметровДоговораДУ\Ext\ManagerModule.bsl`

#### Строка 73 - Функция ЗначенияПараметровДоговораДУ()

- **Код:** `Результат = Запрос.Выполнить();`
- **Описание:** Запрос к регистру сведений для получения актуальных значений параметров договора ДУ на указанную дату. Параметры включают настройки учета, методы списания, счета учета и другие параметры, влияющие на проведение документов.
- **Особенность:** Используется очень часто (6088 обращений), вызывается из множества мест при проведении документов.

---

### 4. ОбщийМодуль.VTB_ОбщийМодуль.Модуль

**Путь:** `CommonModules\VTB_ОбщийМодуль\Ext\Module.bsl`

#### Строка 421 - Функция ПолучитьОткрытыеЗадачиПоСделкеРЕПО()

- **Код:** `Результат = Запрос.Выполнить().Выгрузить();`
- **Описание:** Запрос к объекту "Задача" для получения списка открытых задач по внебиржевым сделкам РЕПО на указанную дату. Используется для контроля выполнения задач по сделкам в бизнес-процессах.
- **Особенность:** Вызывается редко (2 обращения), но занимает много времени на одно обращение (~3 секунды).

---

### 5. БизнесПроцесс.СделкиTn.МодульМенеджера

**Путь:** `BusinessProcesses\СделкиTn\Ext\ManagerModule.bsl`

#### Строка 167 - Функция ПолучитьОткрытыеЗадачиПоСделкеTn()

- **Код:** `Результат = Запрос.Выполнить().Выгрузить();`
- **Описание:** Запрос к объекту "Задача.ВнебиржеваяСделка" для получения списка открытых задач по внебиржевым сделкам Tn на указанную дату. Используется для контроля выполнения задач и обработки плановых позиций.
- **Особенность:** Аналогично функции `ПолучитьОткрытыеЗадачиПоСделкеРЕПО()` в модуле VTB_ОбщийМодуль, но для бизнес-процесса СделкиTn. Вызывается редко, но занимает много времени на одно обращение.
