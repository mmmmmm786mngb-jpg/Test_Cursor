# Анализ блока ВыполнитьСделкиВПотоках()

## Описание

Эта папка содержит BSL модули, необходимые для анализа процедуры `ВыполнитьСделкиВПотоках()` из внешней обработки исполнения сделок T+n.

**Содержит:**
- `ВыполнитьСделкиВПотоках()` - основная процедура для анализа
- `РаспределитьЗадачиПоПотокам()` - распределение задач по потокам
- `ОпределитьНаименееЗагруженныйПоток()` - определение наименее загруженного потока
- `ВыполнитьСделкиПотоки()` - обертка для выполнения сделок в потоках
- Вспомогательные процедуры и функции

## Поток выполнения

1. **ВыполнитьСделкиВПотоках()** (ObjectModule_ExternalProcessor.bsl)
   - Вызывает `РаспределитьЗадачиПоПотокам()` для распределения договоров по потокам
   - Создает фоновые задания для каждого потока
   - Ожидает завершения всех заданий (если `ПроверкаВыполнения = Истина`)

2. **РаспределитьЗадачиПоПотокам()** (ObjectModule_ExternalProcessor.bsl)
   - Выполняет запрос для получения списка договоров с количеством задач
   - Распределяет договоры по потокам, используя алгоритм "наименее загруженный поток"
   - Возвращает таблицу значений с распределением

3. **Фоновое задание: VTB_ОбщийМодуль.ВыполнитьИсполнениеСделокПоСпискуДоговорДУ()** (VTB_CommonModule.bsl)
   - Вызывает `БизнесПроцессы.СделкиTn.ИсполнениеПлановойПозиции()` для исполнения сделок T+n
   - Вызывает `АвтоматическиВыполнитьЗадачиПоСделкеРЕПО()` для исполнения сделок РЕПО

4. **ИсполнениеПлановойПозиции()** (ManagerModule_SdelkiTn.bsl)
   - Получает открытые задачи через `ПолучитьОткрытыеЗадачиПоСделкеTn()`
   - Выполняет задачи последовательно
   - Обрабатывает ошибки и формирует текст отказа

## Ключевые алгоритмы

### Распределение задач по потокам
- Используется алгоритм "Bin Packing" (упаковка в контейнеры)
- Задачи сортируются по убыванию количества задач
- Каждая задача добавляется в наименее загруженный поток
- Цель: равномерное распределение нагрузки между потоками

### Ожидание завершения заданий
- Цикл проверяет состояние всех фоновых заданий
- Завершенные задания удаляются из массива
- Сообщения об ошибках собираются из завершенных заданий
- Цикл продолжается, пока все задания не завершены

## Зависимости

- `ФоновыеЗадания` - для создания и управления фоновыми заданиями
- `БизнесПроцессы.СделкиTn` - для исполнения сделок T+n
- `БизнесПроцессы.СделкиРЕПО` - для исполнения сделок РЕПО
- `Задача.ВнебиржеваяСделка` - виртуальная таблица задач
- `ОбщегоНазначенияКлиентСервер` - для работы с сообщениями пользователю
