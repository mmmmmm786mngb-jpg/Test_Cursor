Описание источников данных

1. Определение Контрагента (запрос втОстаткиОборотыЦБ)

Контрагент определяется в зависимости от типа документа-регистратора операции:

Условие Источник Контрагента Описание
Документ.иц_СводноеПоручение Константа МосковскаяБиржа Для операций по сводным поручениям
Документ.ПогашениеЦБ Константа НРД Для операций погашения ценных бумаг
Документ.ОперацииЦБ Документ.ОперацииЦБ.Контрагент Контрагент из документа операций
Документ.ГлобальнаяОперация
(ВидОперации = Конвертация)		 ЦБ.Эмитент или
ЦБ.БазовыйАктив.Эмитент		 Для конвертации: эмитент базового актива (для ДР) или самой ЦБ
Документ.ГлобальнаяОперация
(ВидОперации ≠ Конвертация)		 Константа МосковскаяБиржа Для других глобальных операций
Документ.КонвертацияЦБ ЦБ.Эмитент или
ЦБ.БазовыйАктив.Эмитент		 Для конвертации: эмитент базового актива (для ДР) или самой ЦБ
Документ.ЦБВПути Документ.ЦБВПути.Контрагент Контрагент из документа "ЦБ в пути"
Иначе "#" Значение по умолчанию

2. Получение наименования (финальный запрос)

После определения контрагента наименование берется из справочника Контрагенты:

Тип контрагента Источник наименования Описание
Юридическое лицо
(ЮрФизЛицо = ЮрЛицо)		 Контрагент.ЮридическиеФизическиеЛица
.ПолноеНаименование		 Полное наименование юридического лица
Преобразуется в строку длиной 255 символов
Физическое лицо Контрагент.ЮридическиеФизическиеЛица
.Наименование		 Наименование (ФИО) физического лица
