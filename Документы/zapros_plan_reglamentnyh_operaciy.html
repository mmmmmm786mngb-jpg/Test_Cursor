Запрос на индексацию

Добрый день, коллеги!
Прошу рассмотреть возможность добавления индексации по реквизиту Портфель для документа ПланРегламентныхОперацийДУ.
Обоснование:

В процессе регламентного задания "Групповое выполнение закрытия периода" для каждого портфеля выполняется поиск документа ПланРегламентныхОперацийДУ по условию Портфель (для перезаписи или создания нового экземпляра).

Учитывая, что в нашей базе 16 миллионов документов ПланРегламентныхОперацийДУ, а портфелей несколько тысяч, операции поиска без индексации по Портфелю существенно замедляют процесс закрытия периода.

Ожидаемый эффект:

Аналогично уже добавленным индексам на документы Сделка и ОперацияПоСчетуБрокера, индексация по Портфелю для ПланРегламентныхОперацийДУ должна значительно ускорить операции поиска и записи этого документа в процессе закрытия периода.

Буду благодарен за рассмотрение данного предложения.
