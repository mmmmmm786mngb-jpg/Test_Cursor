Оптимизация Отчета о финансовом результате по данным ЕПС
IMAPPS-34356
1. Постановка задачи
1.1. Описание проблемы
Отчет "Отчет о финансовом результате по данным ЕПС" (внОтчетОФинансовомРезультате_ЕПС) работал длительное время и создавал повышенную нагрузку на базу данных.
Параметры запуска отчета: Отчетность бухгалтерская => Пользовательские отчеты => Отчет о финансовом результате по данным ЕПС
1.2. Проблемные сценарии
  • ДУ 3225 (без расшифровки) в программе PROD_AVC_FIN20 - долгое время формирования (период: 01.01-30.11.25)
  • ДУ 3546 АО РНПК (с расшифровкой) - выдавал ошибку при формировании
1.3. Требования к оптимизации
Необходимо оптимизировать отчет для снижения времени выполнения и нагрузки на базу данных при сохранении функциональности и корректности расчетов.

Задача 3: Изучить варианты доработок
Вариант А: Замена универсального построителя запроса для "медленных" показателей на объединенный запрос (1 запрос сразу на несколько мелких условий). Преимущества - изменения только в отчете, недостаток - не универсально, ускоряет только конкретные показатели.
Вариант Б: Расчет показателей в фоновых потоках (параллельный расчет). Преимущества - ускоряет расчеты в целом, время формирования всего отчета становится практически равным времени расчета самого долгого показателя, недостаток - требуется создание нового общего модуля в конфигурации.

Реализовать оба варианта оптимизации для обеспечения максимальной эффективности
Выполнено
3. Ход работ
3.1. Анализ кода отчета
В ходе анализа кода были выявлены следующие узкие места производительности:
  • ТОП-4 медленных показателя: П1433 (46.6 сек), П1423 (46.6 сек), П1443 (24 сек), П1413 (23.4 сек) - занимали 59.9% от общего времени выполнения (~140 секунд из 234 секунд)
  • Последовательное выполнение: Все показатели рассчитывались последовательно, что приводило к накоплению времени выполнения
  • Множественные запросы: Для показателей П1423 и П1433 использовалась функция НесколькоУсловий(), что приводило к выполнению двух отдельных запросов вместо одного объединенного
  • Раздел 1_4: Четыре показателя (П1413, П1423, П1433, П1443) выполняли отдельные запросы с общими базовыми условиями

3.3. Созданные объекты конфигурации
Общий модуль: VTB_ОбщийМодуль
  • Свойства модуля: Сервер: true, Внешнее соединение: true, Вызов сервера: true
  • Процедуры модуля: ЗаполнитьПоказателиГруппа1() - ЗаполнитьПоказателиГруппа9() - выполняют расчет показателей соответствующих групп в фоновом задании
  • Особенности реализации: Все процедуры принимают параметры через XML-строку, результаты сохраняются во временное хранилище, ошибки обрабатываются и возвращаются в структуре результата
3.4. Исправление проблемы с расшифровкой
В ходе тестирования была выявлена и исправлена ошибка формирования отчета с расшифровкой. Проблема была связана с неправильной обработкой данных расшифровки при определенных условиях.
Результат исправления:
  • ДУ 3225 без расшифровки: Отчет формируется за 5 минут 27 секунд (период 01.01.25 – 31.10.25), файлы идентичны до и после оптимизации
  • ДУ 3225 с расшифровкой: Отчет формируется за 10 минут 28 секунд (период 01.01.2025 – 31.10.2025), файлы идентичны до и после оптимизации
  • Расшифровка формируется для ДУ 5549 (PROD_AVC_FIN20) для поиска и исправления ошибок
