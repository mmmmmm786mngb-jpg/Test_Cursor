Таблица расчета полей ИдентификаторКонтрагента и ИдентификаторДепонента для формы 444

ВАЖНО: Особенность наименования поля!
На форме карточки Контрагента отображается поле "Нерезидент по паспорту / учредит.документам" (в конфигураторе: Резидент).
Логика работы: Резидент РФ (НЕ Резидент) - когда флаг "Нерезидент по паспорту / учредит.документам" НЕ установлен, Нерезидент (Резидент) - когда флаг "Нерезидент по паспорту / учредит.документам" установлен.

5. Примечания

  • Поле "Нерезидент по паспорту / учредит.документам" (в конфигураторе: Резидент) - на форме карточки Контрагента отображается как "Нерезидент по паспорту / учредит.документам". Когда флаг установлен = нерезидент (иностранец), когда НЕ установлен = резидент РФ.
  • Код страны "643" - это код России по ISO 3166-1 numeric
  • TIN (Tax Identification Number) - используется для нерезидентов (иностранцев)
  • ИНН - используется для резидентов РФ
  • ОГРН - основной государственный регистрационный номер (только для юр. лиц РФ)
  • КПП - код причины постановки на учет (только для юр. лиц РФ)
  • СтраховойНомерПФР - используется для физ. лиц РФ
  • При отсутствии идентификаторов используются заполнители: _000_ для юр. лиц и _00000_ для физ. лиц
  • Все части идентификатора разделяются символом подчеркивания _, кроме случая СтранаФизЛица.Код + ИНН (без разделителя)
