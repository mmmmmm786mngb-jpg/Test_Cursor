Техническое задание: Доработка модуля объекта обработки MF 5. Расчет вознаграждения (валютный)

Объект: Обработка MF РасчетВознаграждения_5_Валютные
Модуль: Ext/ObjectModule.bsl
Функция: ПолучитьСписокИнвестиций(ДоговорДУ, НачалоПериода, КонецПериода)

1. Цель доработки

Изменить структуру запроса в функции ПолучитьСписокИнвестиций: ввести три временные таблицы в заданном порядке, перенести отбор по ДоговорДУ из секции ГДЕ в параметры виртуальной таблицы Обороты (отбор по измерению), ограничить выборку доп. расходов по сделкам только регистраторами из оборотов.

2. Требования к структуре запроса

№Временная таблицаНазначение
1ВТ_ОборотыОбороты регистра бухгалтерии Хозрасчетный за период. Отбор по договору ДУ задается в параметрах виртуальной таблицы Обороты (измерение ДоговорДУ, по аналогии с Организация в типовой 1С:Бухгалтерия), не в ГДЕ.
2ВТ_ЗатратыДоп. расходы по сделкам (Документ.Сделка.ДопРасходы) только по тем сделкам, которые являются регистраторами строк из ВТ_Обороты (связь по Регистратор = Ссылка). Условие ВключатьВСтоимость = ИСТИНА сохраняется.
3ВТ_ОперацииСоединение: ВТ_Обороты + ЛЕВОЕ СОЕДИНЕНИЕ ВТ_Затраты + ЛЕВОЕ СОЕДИНЕНИЕ регистр сведений КурсыВалют.СрезПоследних. Секции ГДЕ по ДоговорДУ нет.

3. Текущая реализация (фрагмент)

Сейчас: сначала формируется ВТ_Затраты по всем сделкам договора ДУ; затем втОперации из Обороты с ГДЕ ДоговорДУ = &ДоговорДУ. 
ВЫБРАТЬ
	СделкаДопРасходы.Ссылка,
	СУММА(ЕСТЬNULL(СделкаДопРасходы.Стоимость, 0)) КАК Стоимость
ПОМЕСТИТЬ ВТ_Затраты
ИЗ
	Документ.Сделка.ДопРасходы КАК СделкаДопРасходы
ГДЕ
	СделкаДопРасходы.ВключатьВСтоимость = ИСТИНА
	И СделкаДопРасходы.Ссылка.ДоговорДУ = &ДоговорДУ
СГРУППИРОВАТЬ ПО
	СделкаДопРасходы.Ссылка
;

ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ХозрасчетныйОбороты.Период,
	...
ПОМЕСТИТЬ втОперации
ИЗ
	РегистрБухгалтерии.Хозрасчетный.Обороты(&НачПериода, &КонПериода, Регистратор,
		Счет В (...), , ,
		КорСчет В ИЕРАРХИИ (...), ) КАК ХозрасчетныйОбороты
	ЛЕВОЕ СОЕДИНЕНИЕ ВТ_Затраты КАК ВТ_Затраты
		ПО ХозрасчетныйОбороты.Регистратор = ВТ_Затраты.Ссылка
	ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.КурсыВалют.СрезПоследних(&КонПериода, ) ...
ГДЕ
	ХозрасчетныйОбороты.ДоговорДУ = &ДоговорДУ
;

4. Целевая реализация (пример кода)

4.1. Первый фрагмент: ВТ_Обороты

Отбор по договору ДУ передается в виртуальную таблицу как отбор по измерению ДоговорДУ = &ДоговорДУ (порядок параметров — по метаданным регистра Хозрасчетный).

ВЫБРАТЬ
	ХозрасчетныйОбороты.Период,
	ХозрасчетныйОбороты.Регистратор,
	ХозрасчетныйОбороты.Счет,
	ХозрасчетныйОбороты.Субконто1 КАК Актив,
	ЕСТЬNULL(ХозрасчетныйОбороты.Валюта, ЗНАЧЕНИЕ(Справочник.Валюты.RUB)) КАК Валюта,
	ЕСТЬNULL(ХозрасчетныйОбороты.СуммаОборотДт, 0) КАК Сумма,
	ЕСТЬNULL(ХозрасчетныйОбороты.ВалютнаяСуммаОборотДт, 0) КАК ВалСумма
ПОМЕСТИТЬ ВТ_Обороты
ИЗ
	РегистрБухгалтерии.Хозрасчетный.Обороты(&НачПериода, &КонПериода, Регистратор,
		Счет В (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ДепозитныеСчетаВРублях), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ДепозитныеСчетаВВалюте), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.АкцииТело), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ОблигацииТело), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ВекселяТело), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ПаиТело), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ИпотечныеСертификатыТело), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.СтоимостьСтруктурнойНоты), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.УплаченныйНКД)), , ,
		КорСчет В ИЕРАРХИИ (ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыЦБПокупка), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетыБрокера55), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.РасчетныеСчета), ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ТекущиеСчета)),
		ДоговорДУ = &ДоговорДУ) КАК ХозрасчетныйОбороты
;

4.2. Второй фрагмент: ВТ_Затраты

Только сделки, являющиеся регистраторами строк из ВТ_Обороты (внутреннее соединение с ВТ_Обороты по Ссылка = Регистратор).

ВЫБРАТЬ
	СделкаДопРасходы.Ссылка,
	СУММА(ЕСТЬNULL(СделкаДопРасходы.Стоимость, 0)) КАК Стоимость
ПОМЕСТИТЬ ВТ_Затраты
ИЗ
	Документ.Сделка.ДопРасходы КАК СделкаДопРасходы
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ ВТ_Обороты КАК ВТ_Обороты
		ПО СделкаДопРасходы.Ссылка = ВТ_Обороты.Регистратор
ГДЕ
	СделкаДопРасходы.ВключатьВСтоимость = ИСТИНА
СГРУППИРОВАТЬ ПО
	СделкаДопРасходы.Ссылка
;

4.3. Третий фрагмент: ВТ_Операции

Соединение ВТ_Обороты с ВТ_Затраты и КурсыВалют. Секции ГДЕ нет.

ВЫБРАТЬ РАЗРЕШЕННЫЕ
	ВТ_Обороты.Период,
	ВТ_Обороты.Регистратор,
	ВТ_Обороты.Счет,
	ВТ_Обороты.Актив,
	ВТ_Обороты.Валюта,
	ВТ_Обороты.Сумма,
	ВТ_Обороты.ВалСумма,
	ЕСТЬNULL(ВТ_Затраты.Стоимость, 0) КАК Затраты,
	КурсыВалютСрезПоследних.Курс КАК Курс,
	КурсыВалютСрезПоследних.Период КАК ДатаКурса
ПОМЕСТИТЬ ВТ_Операции
ИЗ
	ВТ_Обороты КАК ВТ_Обороты
		ЛЕВОЕ СОЕДИНЕНИЕ ВТ_Затраты КАК ВТ_Затраты
		ПО ВТ_Обороты.Регистратор = ВТ_Затраты.Ссылка
		ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.КурсыВалют.СрезПоследних(&КонПериода, ) КАК КурсыВалютСрезПоследних
		ПО ВТ_Обороты.Валюта = КурсыВалютСрезПоследних.Валюта
;

4.4. Итоговая выборка валют и цикл

Источник для списка валют и для выборки операций по валюте — временная таблица ВТ_Операции. Имя псевдонима при выборке из неё можно оставить втОперации для совместимости с существующим циклом.

ВЫБРАТЬ РАЗЛИЧНЫЕ
	ВТ_Операции.Валюта
ИЗ
	ВТ_Операции КАК ВТ_Операции

В цикле по валютам второй запрос выбирает из ВТ_Операции по условию ВТ_Операции.Валюта = &Валюта (поля Период, Регистратор, Счет, Актив, Валюта, Сумма, ВалСумма, Затраты, Курс, ДатаКурса).

5. Важные замечания

  • ДоговорДУ — измерение регистра бухгалтерии Хозрасчетный (аналогично измерению «Организация» в типовой 1С:Бухгалтерия). В вызове виртуальной таблицы Обороты указывается отбор по измерению в параметрах VT; точный порядок параметров уточнить по метаданным регистра.
  • Набор счетов и условие по КорСчет в вызове Обороты не менять (как в текущем коде).
  • Параметры запроса: &НачПериода, &КонПериода, &ДоговорДУ — без изменений. Менеджер временных таблиц используется по-прежнему.

6. Критерии приемки

  • Запрос состоит из трех временных таблиц: ВТ_Обороты, ВТ_Затраты, ВТ_Операции в указанном порядке.
  • В вызове Обороты присутствует отбор по измерению ДоговорДУ = &ДоговорДУ; в секции ГДЕ отбора по ДоговорДУ нет.
  • ВТ_Затраты формируется только по сделкам-регистраторам из ВТ_Обороты (ВНУТРЕННЕЕ СОЕДИНЕНИЕ с ВТ_Обороты).
  • ВТ_Операции строится из ВТ_Обороты с ЛЕВЫМ соединением ВТ_Затраты и ЛЕВЫМ соединением КурсыВалют.
  • Результат расчета вознаграждения (состав валют, суммы, курс) для тестового договора ДУ и периода совпадает с результатом до доработки.
